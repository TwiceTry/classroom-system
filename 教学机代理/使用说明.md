# 教学机代理（局域网 → 公网）

教学机上有两块网卡：一块连**学生机的局域网**，一块通**公网**。
**课堂系统只部署在公网上**（那一份就是唯一的一份），教学机本机和局域网里都**不部署**课堂系统。
学生机在局域网里直接访问公网地址不稳 / 不通 —— 这个代理就在教学机上开一个端口，
把请求原样转给公网地址，顺带把静态资源缓存下来（省公网带宽）。

```
学生机（局域网）        教学机（只跑代理）              公网（唯一一份课堂系统）
┌──────────────┐  http://<教学机IP>:<端口>  ┌────────────┐  https  ┌──────────────┐
│ 浏览器        │ ────────────────────────▶ │ lan-proxy  │ ──────▶ │ 课堂系统      │
│              │                           │ + 缓存      │         │ 课程/班级/…   │
└──────────────┘                           └────────────┘         └──────────────┘
```

所以代理只干两件事：

1. **转发**：把学生机的请求原样送到公网地址（页面、接口、静态资源、投屏的 WebSocket 都一样）
2. **缓存**：把公开的静态资源缓存在教学机上 —— 第一个学生出公网，后面都本地命中
   （打开一次「代码练习」页就是 2.5MB；30 个学生各开一次 = 75MB 全走公网隧道，
   有了缓存只出 2.5MB）

> 代理**不做任何分流**：课堂系统只有公网那一份，投屏（`/ws`）、点名、在线状态
> 与页面走同一条路（都去公网）。

## 一、这个文件夹里有什么

| 文件 | 作用 | 入库吗 |
|---|---|---|
| `lan-proxy.py` | 代理本体（**只用 Python 标准库，没有任何第三方依赖**） | ✅ 入库 |
| `启动代理.bat` | 双击启动（优先用自带的内嵌 Python） | ✅ 入库 |
| `proxy.example.conf` | 配置**样例** | ✅ 入库 |
| `使用说明.md` | 本文件 | ✅ 入库 |
| `proxy.conf` | 你的**实际配置**（含教学机 IP 与公网地址） | ❌ **不入库** |
| `runtime/python/` | 内嵌 Python 3.8.10（Win7 能跑的最后一版，约 20 MB） | ❌ **不入库** |
| `deps/` | 第三方依赖的落点（一般用不到，空着即可） | ❌ **不入库** |

> **为什么内嵌 Python 也不入库**：它是二进制大文件（20MB），每台机器自己放一份更合适。
> 需要的话从这里下（官方原版，7.8MB 的 zip）：
> <https://www.python.org/ftp/python/3.8.10/python-3.8.10-embed-amd64.zip>
> 解压到 `runtime\python\` 即可（解压后约 20MB）。

## 二、第一次用（三步）

```bat
rem 1) 复制配置
copy proxy.example.conf proxy.conf

rem 2) 用记事本打开 proxy.conf，把地址填好（第三节讲填什么）

rem 3) 双击 启动代理.bat
```

窗口里会打印将要开什么：

```

================================================================

  缓存：开 · 上限 64 MB · 静态 365 天 / 示例 1 天 / 讲义 60 秒
  配置文件：…\proxy.conf（改完重启生效）

  停止：Ctrl + C

```

学生机浏览器打开 `http://<教学机的局域网IP>:18799` 即可。

## 三、配置填什么

`proxy.conf` 是纯文本（`#` 开头是注释），要改的只有前两项：

| 键 | 填什么 | 例子 |
|---|---|---|
| `listen.port` | 学生机访问的端口 | `18799` |
| `listen.host` | 只监听某块网卡时填教学机局域网 IP；**留空 = 都听**（一般不动） | `192.168.5.226` |
| `target` | **必填**：公网上游地址 | `https://forum.r85269122.nyat.app:45600` |
| `tls.insecure` | 上游证书自签/过期时填 `yes`（跳过校验） | `no` |
| `timeout.ms` | 上游多久没回话算超时（毫秒） | `120000` |
| `log.verbose` | 填 `yes` 打印每条请求的状态码与耗时 | `no` |
| `cache.enabled` | 要不要缓存（见下面「缓存」一节） | `yes` |
| `cache.maxbytes` | 缓存最多占多少内存（字节） | `67108864`（64MB） |
| `cache.maxentries` | 最多缓存多少条 | `500` |
| `cache.ttl.assets` | 前端产物（带哈希）缓存多久（秒） | `31536000`（一年） |
| `cache.ttl.static` | 示例运行时库 / 图片缓存多久（秒） | `86400`（一天） |
| `cache.ttl.content` | 讲义 / 材料正文缓存多久（秒） | `60` |

改完**重启代理**才生效（关掉窗口再双击）。

## 四、不分流：所有流量都走公网

课堂系统只有公网那一份，所以代理不按路径分流 —— 页面、接口、静态资源、
投屏的 `/ws`（WebSocket）全部转给同一个上游。这样最省心，也不会有
「一半本地一半公网」导致的数据对不上的问题。

## 五、系统里什么最耗资源（实测）

先量了一遍「一个学生打开一次代码练习页」要从公网拉多少东西（走公网隧道）：

| 资源 | 大小 | 说明 |
|---|---|---|
| `/examples/vue3-sfc-loader.js` | **1.76 MB** | 单页运行时库（SFC 编译器），最大头 |
| `/examples/vue.global.js` | **580 KB** | Vue 全局版 |
| `/assets/index-*.js` | 118 KB | 前端主包（带内容哈希） |
| `/vendor/marked.min.js` | 35 KB | 讲义里的 markdown 渲染 |
| `/assets/index-*.css` | 14 KB | 样式 |
| 首页 HTML + favicon + `playground/sfc-boot.js` | 22 KB | |
| **合计** | **2.50 MB** | 每个学生每次打开都重来一遍 |

**瓶颈不是服务器，是公网隧道的下行带宽**：这些文件的 `Cache-Control` 全是 `no-cache`，
所以浏览器每次都重新下载。30 个学生每节课各开一次 = **75 MB 全走公网**。

（顺带说明：真正吃服务器的是「扫目录 + 读 CSV」那部分，但一次页面加载只扫几个目录，
远小于 2.5MB 的下载量。所以先解决下载。）

## 六、缓存（代理 + 缓存，已默认开启）

代理在教学机上开一个**内存缓存**，只缓存**公开的 GET/HEAD**：

- **课程材料**（学生讲义）现在是公开内容（不需要登录）→ 可以缓存，缓存键里不带身份
- **讲义**（教师讲稿）→ 路径上就排除掉；上游还会回 `private, no-store`，代理看到就不存（双保险）
- 教师端 / 学生端接口 → 一律不进缓存

| 路径 | 缓存多久 | 为什么 |
|---|---|---|
| `/assets/*`（前端产物，文件名带内容哈希） | 1 年 | 内容变了就换文件名，可以永久缓存 |
| `/vendor/*`、`/examples/*`、图片 | 1 天 | 极少变 |
| `/api/content/doc?type=materials`（**课程材料**，公开内容） | 60 秒 | 老师改完课很快能生效 |
| `/api/content/doc?type=lecture`（**讲义**，教师内容） | **不缓存** | 教学公开原则：教师讲稿不进任何缓存 |
| 其它（`/api/teacher/*`、`/api/student/*`、`/ws`…） | **不缓存** | 个性化数据 / 长连接 |

另外它还会**改写 `Cache-Control`** 发给浏览器（`public, max-age=…`），
所以**浏览器自己也会把文件存到磁盘** —— 学生第二次打开代码练习页，浏览器直接用本地缓存，
连代理都不用问。

命中时会带上两个头，方便排查：

```
X-Cache: HIT   Age: 12
```

### 实测（30 个学生依次打开代码练习页，都走公网隧道）

| | 出公网的字节 | 总耗时 | 第 1 个学生 | 第 2 个 | 第 30 个 |
|---|---|---|---|---|---|
| 不开缓存 | 75.3 MB | 3457 ms | — | — | — |
| **开缓存** | **2.5 MB（省 97%）** | **683 ms** | 119 ms | **8 ms** | **12 ms** |

（客户端下载的字节数不变 —— 每个浏览器总得自己收一份；省下的是**出公网的流量**和**等待时间**。）

### 看缓存效果

```bash
curl http://127.0.0.1:18799/__proxy_stats
# {"ok":true,"cacheEnabled":true,
#  "cache":{"entries":8,"bytes":1963418,"maxBytes":67108864,"hits":203,"misses":7,"hitRate":0.97}, …}
```

### 缓存的边界（重要）

- **带令牌的请求不缓存**：教师端/学生端的接口都是个性化数据，缓存了就是串数据
- **只缓存 200**：403/404/5xx 都不进缓存
- **尊重上游的 `Cache-Control`**：上游说 `no-store` / `private` 的响应一律不存
- **讲义正文只缓存 60 秒**：老师改完讲义，学生最多 1 分钟后看到新内容（想立刻生效就把它调成 10 秒）
- 缓存在**内存**里：代理重启就没了（第一次访问重新出公网拉一次）
- 上限 64MB：够装下所有前端资源与示例运行时库（约 2MB），超了按最近最少使用淘汰

## 七、它做了什么（细节）

- **透传**：方法、请求体（含分块）、压缩（`Accept-Encoding` 原样带走）、响应体流式转发（不缓冲）
- **改写两处**：上游 `Location` 里的绝对地址 → 改成学生机看到的地址（否则 302 会把人甩到公网）；
  `Set-Cookie` 里的 `Domain=` → 去掉（否则学生机存不下 cookie）
- **补三个头**：`X-Forwarded-For` / `X-Forwarded-Proto` / `X-Forwarded-Host`（上游能看到真实客户端 IP）
- **WebSocket**：`/ws` 的升级握手自己拼报文、再双向转发（投屏画面帧与同步代码靠它）
- **错误分得清**：本机那侧连不上 → 提示「确认课堂系统在本机跑着」；公网那侧连不上 → 提示连不上上游
- **超时**：上游 `timeout.ms` 没回话 → 504

## 八、自检

```bash
# 代理活着吗（教学机本机）
curl http://127.0.0.1:18799/__proxy_health

# 能通到上游吗
curl http://127.0.0.1:18799/api/health

# 学生机通吗（在学生机上跑）
curl http://192.168.5.226:18799/api/health
```

打不开 → 依次查：代理窗口还在吗 → 防火墙放行了吗 → `proxy.conf` 里的 `target` 对不对 → 公网那头服务在跑吗。

## 九、Win7 防火墙放行（一次）

管理员身份的命令提示符：

```bat
netsh advfirewall firewall add rule name="classroom-proxy" dir=in action=allow protocol=TCP localport=18799
```

删掉：

```bat
netsh advfirewall firewall delete rule name="classroom-proxy"
```

## 十一、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 启动器说找不到 python | 把内嵌 Python 解压到 `runtime\python\`，或装 Python 并加进 PATH |
| 启动器说找不到 proxy.conf | 复制 `proxy.example.conf` 改名为 `proxy.conf` |
| 窗口一闪而过 | 双击运行 bat（cmd 窗口才会停住）；或直接 `runtime\python\python.exe lan-proxy.py --config proxy.conf` |
| 学生机打不开 | 防火墙没放行；或 `listen.host` 填成了别的网卡 |
| 页面能开但图片/接口 404 | 上游地址（`target`）填错了 |
| 投屏卡 / 点名不动 | 投屏与点名都走公网（`/ws`），先看公网那头通不通；带宽不够时把代理的 `cache.ttl.static` 调大 |
| 上游证书报错 | `tls.insecure = yes` |
| 想临时改端口 | 命令行加 `--port 18800`（覆盖配置） |
| 要装第三方包 | 装到 `deps\` 目录即可（已在 `python38._pth` 的搜索路径里）；不过本脚本不需要任何第三方包 |
| 学生说代码练习页打开慢 | 多半是公网带宽被占；看 `/__proxy_stats` 的命中率（越高越好），必要时把 `cache.ttl.static` 调大 |
| 老师改了讲义，学生还是旧的 | 讲义正文缓存 `cache.ttl.content` 秒（默认 60）；改完等一分钟，或把它调小 |
