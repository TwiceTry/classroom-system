课程材料模板（materials/ = 学生讲义）

一、这一份是什么
--------------
学生向：学什么（知识点 + 原理 + 练习 + 拓展）。学生端「课程材料」看到的就是它。

必须包含
  · 知识目标与知识点讲解（学生能直接看懂）
  · 关键代码与原理
  · ✅ 自测与练习（作业 1 ~ 作业 N，最实操的那题升级为可提交作业）
  · 📚 拓展阅读（加分 / 拔高）
  · 🧪 配套代码：一行指向 代码示例/第NN课-XXX/，并说一句「打开后能看到什么」

禁止出现（这些属于 lecture/）
  · 教师向 / 教务向：90 分钟、代替 PPT、板书标记、评分量规、授课计划、课时分配
  · 讲法提示：💬 提问、⚠️ 易错预警、演示动作、时间分配

二、命名与对应
-----------
  第NN课-XXX.md    正课（01 或 1 都认，按编号排课次）
  补充-XXX.md      补充资料，排在所有正课之后
  三处同名同号：lecture/第05课-响应式.md ↔ materials/第05课-响应式.md ↔ 代码示例/第05课-响应式/

三、和讲义的小节对应（小节锚点约定）
------------------------------
  · 讲义里带 ### 📺 屏幕 的节，材料里必须有同名标题 —— 📺 是「这节要给学生看」的开关
  · 层级不同是正常的：
        讲义：## 知识块  →  ### 📺 屏幕  →  #### 细节点
        材料：## 知识块  →  ### 细节点
  · 两侧标题写成同一个（忽略行内标记、全角半角冒号、括号形状、空白、英文大小写；
    emoji、用词、标点不忽略）
  · 一屏讲完：正文 ≤ 900 字、代码块 ≤ 3 个、表格 ≤ 12 行；超了就在两侧同时拆一级

四、改完怎么自证
------------
  cd 课堂系统
  node server/check-sections.js           只报错与超标清单
  node server/check-sections.js --report  生成一份可勾选的待改清单

五、导入
------
  讲义页切到「课程材料」视图 → 导入课程材料（根目录就是这些 .md，别再套一层文件夹）。
  「整体替换」会把本地多出来的材料移进 data/.trash/，可捞回。

六、完整规范
----------
