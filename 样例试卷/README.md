# 样例试卷

给机试（期末机试 / 阶段测试）用的卷子，JSON 格式，直接在教师端导入。

## 怎么用

```
期末机试 → 点一份机试 → 「导入这份卷子（JSON）」 → 选这里的文件
```

导进去之后：

```
确认卷面   控制台会显示「统一卷（全班同一份）· 100 分 · 限时 45 分钟 · 四段(N题)」
开考      点「▶ 开始考试」，学生端立刻能开考并开始计时
判分      选择题 / 判断题 / 填空题交卷即自动判；简答题在批阅界面手工给分
```

## 现有卷子

| 文件 | 类型 | 每人做题 | 题池 | 卷面 | 限时 |
|---|---|---|---|---|---|
| `测试卷-Vue基础.json` | 固定卷 | 22 题 | — | 100 分 | 45 分钟 |
| `题库-Vue基础.json` | **题库卷** | 17 题 | 31 题 | 100 分 | 45 分钟 |
| `判分演示-部分分.json` | 固定卷 | 5 题 | — | 50 分 | 20 分钟 |

第三份**只用来演示判分规则**（见 `判分规则.md`），题量小、每段一个考点：

```
一、多选 partial: true   2 题   同一道多选，漏选给 6.7 分
二、多选 默认（严格）    1 题   对照：同样漏选给 0 分
三、判断                1 题   √ ✓ true 是 都算对
四、填空                1 题   ｒｅｆ（全角）/ Re f（空格）都算对
```

导入后拿它试判分，四种作答的得分直接对得上规则表。

### 固定卷 配分

选择 10×4 + 判断 5×4 + 填空 5×4 + 简答 2×10 = **100**

### 题库卷 配分

| 段 | 题池 | 抽 | 每题 | 小计 |
|---|---|---|---|---|
| 一、选择 | 10 | 5 | 6 分 | 30 |
| 二、判断 | 8 | 4 | 5 分 | 20 |
| 三、填空 | 8 | 5 | 4 分 | 20 |
| 四、简答 | 5 | 3 | 10 分 | 30 |
| | **31** | **17** | | **100** |

每人抽到的具体题目不同，但题量和卷面分完全一样（同分公平）。
防抄的用法：一屋子人同时考，抽题不同等于每人一份卷子。

## 卷子格式

```json
{
  "kind": "paper",           // paper = 统一卷（全班同一份）
                             // bank  = 题库随机卷（每人抽不同的题，要给 pick）
  "title": "卷子标题",
  "duration": 45,            // 限时（分钟）。0 表示不限时
  "fullScore": 100,          // 可省略，会按分段自动算
  "sections": [
    {
      "id": "s1",
      "title": "一、选择题",
      "type": "choice",      // choice 选择 / judge 判断 / fill 填空 / short 简答
      "score": 4,            // **这一段的每题分值**（分值在段上，不在题上）
      "questions": [
        {
          "id": "c1",        // 全卷唯一
          "stem": "题干",
          "options": ["A 选项文字", "B 选项文字"],   // choice 必填，至少 2 个
          "answer": "B",     // choice 填字母（多选写 "ABD"）；judge 填 对/错；fill 填标准答案
          "accepts": [],     // fill 用：其它也算对的写法，如 ["ref", "Ref()"]
          "explain": "解析，老师判卷时能看到"
        }
      ]
    }
  ]
}
```

### 三种题型的答案写法

| 题型 | answer | 自动判 |
|---|---|---|
| `choice` | 选项字母，多选连写 `"ABD"` | 严格比对字母集合（大小写不敏感） |
| `judge` | `"对"` / `"错"`（也认 true/false、T/F、是/否） | 严格比对 |
| `fill` | 标准答案 + `accepts` 里的备选 | 去空白、忽略大小写后比对 |
| `short` | 不判，写参考要点即可 | 交卷后老师手工给分 |

### 题库随机卷（kind: "bank"）

每个人抽到的题不一样，防抄。多给一段 `pick`：

```json
{ "id": "s1", "type": "choice", "score": 4, "pick": 6,
  "questions": [ … 20 道题 … ] }     // 从 20 道里抽 6 道
```

`pick` 不能大于题池大小，否则校验不过。

### ⚠️ 题库卷的 `fullScore` 不用写

**题库卷的卷面分按「每段 pick × 每题分」自动算，JSON 里写的不作数。**

比如题池 31 题但每段只抽 5/4/5/3 道，实际卷面是 100 分 ——
你在 JSON 里写 `"fullScore": 200` 也没用，系统会按 pick 算成 100。

- 为什么这么设计：题库卷的 `questions` 是**题池**，不是学生要做的题。
  照着「题池全上」写个总分，会和实际卷面差一大截，
  而一旦和考核方案的「卷面折算」对不上，学生全对也拿不满分。
- 固定卷（`kind: "paper"`）相反，`fullScore` 会用你写的值（可以出 80 分小卷）。

如果写了和实际不一致的数，**导入时会有一条提醒**告诉你实际是多少。

## 改卷子时的两个坑

**① `score` 在段上，不在题上**

写 4 分的题，段上写 `"score": 4`，题目里不要再写。写了也不生效。

**② 卷面总分要和考核方案对得上**

方案里「机试」这一项有「卷面折算」：比如卷面 100 折 24 分。
如果卷子只出了 50 分，全对也只有 `50 × 0.24 = 12` 分，剩下的 12 分永远拿不到 ——
导卷时控制台会提示，但不会拦。出卷前先看一眼方案里那个「卷面 X 分」。
