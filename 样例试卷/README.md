# 样例试卷

给机试（期末机试 / 阶段测试）用的卷子，JSON 格式，直接在教师端导入。

## 怎么用

```
期末机试 → 点一份机试 → 「导入这份卷子（JSON）」 → 选这里的文件
```

导进去之后：

```
确认卷面   控制台会显示「统一卷（全班同一份）· 100 分 · 限时 45 分钟 · 四段(N题)」
开考      点「▶ 开始考试」，学生端立刻能开考并开始计时
判分      选择题 / 判断题 / 填空题交卷即自动判；简答题在批阅界面手工给分
```

## 现有卷子

| 文件 | 题量 | 卷面 | 限时 | 自动判 | 留给老师 |
|---|---|---|---|---|---|
| `测试卷-Vue基础.json` | 4 段 22 题 | 100 分 | 45 分钟 | 80 分 | 20 分（2 道简答） |

配分：选择 10×4 + 判断 5×4 + 填空 5×4 + 简答 2×10 = **100**

## 卷子格式

```json
{
  "kind": "paper",           // paper = 统一卷（全班同一份）
                             // bank  = 题库随机卷（每人抽不同的题，要给 pick）
  "title": "卷子标题",
  "duration": 45,            // 限时（分钟）。0 表示不限时
  "fullScore": 100,          // 可省略，会按分段自动算
  "sections": [
    {
      "id": "s1",
      "title": "一、选择题",
      "type": "choice",      // choice 选择 / judge 判断 / fill 填空 / short 简答
      "score": 4,            // **这一段的每题分值**（分值在段上，不在题上）
      "questions": [
        {
          "id": "c1",        // 全卷唯一
          "stem": "题干",
          "options": ["A 选项文字", "B 选项文字"],   // choice 必填，至少 2 个
          "answer": "B",     // choice 填字母（多选写 "ABD"）；judge 填 对/错；fill 填标准答案
          "accepts": [],     // fill 用：其它也算对的写法，如 ["ref", "Ref()"]
          "explain": "解析，老师判卷时能看到"
        }
      ]
    }
  ]
}
```

### 三种题型的答案写法

| 题型 | answer | 自动判 |
|---|---|---|
| `choice` | 选项字母，多选连写 `"ABD"` | 严格比对字母集合（大小写不敏感） |
| `judge` | `"对"` / `"错"`（也认 true/false、T/F、是/否） | 严格比对 |
| `fill` | 标准答案 + `accepts` 里的备选 | 去空白、忽略大小写后比对 |
| `short` | 不判，写参考要点即可 | 交卷后老师手工给分 |

### 题库随机卷（kind: "bank"）

每个人抽到的题不一样，防抄。多给一段 `pick`：

```json
{ "id": "s1", "type": "choice", "score": 4, "pick": 6,
  "questions": [ … 20 道题 … ] }     // 从 20 道里抽 6 道
```

`pick` 不能大于题池大小，否则校验不过。

## 改卷子时的两个坑

**① `score` 在段上，不在题上**

写 4 分的题，段上写 `"score": 4`，题目里不要再写。写了也不生效。

**② 卷面总分要和考核方案对得上**

方案里「机试」这一项有「卷面折算」：比如卷面 100 折 24 分。
如果卷子只出了 50 分，全对也只有 `50 × 0.24 = 12` 分，剩下的 12 分永远拿不到 ——
导卷时控制台会提示，但不会拦。出卷前先看一眼方案里那个「卷面 X 分」。
