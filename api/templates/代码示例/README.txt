代码示例模板（代码示例/ = 可运行实例，同时是发给学生的分发包）

一、命名与对应（三方职能约定）
------------------------
  第NN课-XXX/        和 lecture、materials 三处同名同号
  补充-XXX/          补充课不占课次编号（如 补充-JS基础复习），三处同名
  目录名会被解析成「第 N 课 · 标题」，所以名字里照写「第01课-课程标题」即可。

二、这一份模板
------------
  第01课-示例标题/
      index.html   页面（双击即打开）
      main.js      脚本
      style.css    样式
  纯静态、零依赖：双击 index.html 就能跑，适合第 1 课和复习用。

三、硬性要求
----------
  · 每个 .html 都会出现在「预览页面 ▾」下拉里，建议至少有一个 index.html
  · 讲义 / 材料里讲到的每个 ✅ 自测、💡 案例、反例，在这里都能找到对照实现
  · 图片放 assets/，用相对路径引用
  · 名字为 playground 的目录是通用工具目录，不当示例；node_modules/、.git/ 不进包

四、进阶结构（第 02~11 课用的 Vue 单文件组件）
--------------------------------------
  这些课不是纯静态，用「官方运行时 SFC 加载器」，仍然不用构建：

      代码示例/
          vue.global.js          公共运行时（整个目录拷给学生时一起带）
          vue3-sfc-loader.js
          playground/sfc-boot.js 通用启动脚本
          第05课-响应式/
              index.html         纯壳：只引上面三行依赖
              main.mjs           入口：import App from './App.vue' + createApp(App).mount('#app')
              App.vue            业务与布局都在这里
              components/*.vue   子组件

  · 一课多页（课堂实验台 / 进阶 demo）：再加一个 xxx.html（同样三行依赖，启动脚本上加
    data-entry="xxx.mjs"）+ xxx.mjs + Xxx.vue，预览下拉会自动列出这个页面
  · 练习型补充课（补充-XXX）：
        index.html   渲染页 + 判分框架（学生不改）
        q1.js ~ qN.js 学生逐题作答，题号与 materials 里 ✅ 自测 一一对应，不许换号
        demo.html    需要演示对照时再给
    判分框架要保证「Playground 里改 qN.js 立刻重跑」与「双击 index.html 读磁盘 .js」表现一致

五、当前支持范围（重要）
------------------
  代码练习 / 课堂作业的在线工作台目前**只支持 Vue 单文件组件这一套**（含纯静态 HTML/JS/CSS）。
  React、TypeScript 编译、Vite 工程、Python / Java 等运行体系暂不支持 —— 那些课的内容
  仍然可以放进 代码示例/（学生能看、能双击跑），只是工作台里的在线编辑与预览不适用。

六、分发（很关键）
------------
  学生拿到的不是 git clone，而是**整个 代码示例/ 目录的拷贝**。
  所以：
  · 公共运行时（vue.global.js、vue3-sfc-loader.js、playground/）必须留在根目录
  · 发之前删掉教师侧 / 含隐私的文件（名单、成绩、本 README 之类）
  · 学生机器只需：双击安装 Chrome → 双击各课 index.html

七、导入 / 导出
------------
  代码练习页头：[⤓ 导出代码练习] [⤒ 导入代码练习] [模板]
  包里第一层就是这些课目录（不要再套一层）；「整体替换」会把本地多出来的目录移进 data/.trash/。
