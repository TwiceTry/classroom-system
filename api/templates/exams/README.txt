试卷模板（exams/ = 机试试卷与笔试试卷）

一、放什么
--------
  一份机试卷 = 一个 .json（字段见《机试试卷格式规范.md》，本包里的 试卷模板.json 直接改）
  笔试试卷 = 一个 .md（只供查看 / 打印，不参与自动判分）

二、两种出卷模式（JSON 里的 kind）
---------------------------
  paper 统一卷：全班同一份题
  bank  题库随机卷：每个分段从题库里随机抽 pick 道，适合期末

三、也可以不用 json
-------------
  「期末机试」页里「＋ 新建机试」可以图形化出题，出的卷子同样落在 exams/，
  和手工放进来的 json 是一回事（同一份文件，两边都能看到）。

四、判分与产出
----------
  · 客观题自动判，主观题老师判
  · 交卷后每个学生名下生成答卷（md + html），
    老师评分记在该学生的 机试/成绩.xlsx（给分后自动重写）
  · 导入时会逐条校验：字段缺失、分数对不上、题号重复都会明确报出来

五、导入 / 导出
-----------
  期末机试页头：[⤓ 导出试卷] [⤒ 导入试卷] [模板]
  只搬 exams/ 这一个目录，不动课程信息、方案、名单。

六、完整规范
--------
