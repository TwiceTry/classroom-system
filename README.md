# 课堂系统（Web 版）

> **当前版本 2.0.0**：后端已换成 Fastify + SQLite，不再有 CSV 数据文件。

> **这是一个独立的公开仓库**：系统本体（服务端 + 前端 + 部署脚本），**不含任何课程资料**。
> 讲义 / 材料 / 代码示例 / 试卷都是「外部内容目录」，用配置指过去即可（见下面《目录关系》）。
> 数据（课程、班级、名单、成绩、学生提交）全在 `data/`，默认**不入库**。
>
> ```bash
> # 拉现成镜像起一个（数据在 ./data）
> docker pull ghcr.io/twicetry/classroom-system:latest
> docker run -d --name classroom-system -p 18730:18730 \
>   -e TS_PASSWORD=你的口令 -v "$PWD/data:/data" ghcr.io/twicetry/classroom-system:latest
> ```

**独立的一套系统**：跑在教师机上的 Node 服务 + Vue3 前端，教师端 / 学生端分角色，数据与分数在服务端统一，
学生机零安装、只用浏览器。它**不依赖、也不包含**任何课程资料 —— 讲义 / 材料 / 代码示例是「外部内容目录」，
用配置指过去即可（见下）。

| 系统里的页面 | 路径 |
|---|---|
| 讲义 / 课程材料 | `/teacher/lecture`、`/student/materials` |
| 投屏 | `/teacher/screen` + 学生端 `/watch` |
| 考勤点名（**点一下就存**，网格 / 列表两种视图，只记异常） | `/teacher/modules/<考勤项>`（老地址 `/teacher/attendance` 会重定向） |
| 课堂互动（随机点名 + 当场加减分） | `/teacher/modules/<互动项>` |
| 班级管理（名单只读分数 + 全班流水；原「计分管理」已并入，但**不在这里记分/点名**；页头「班级与名单」可把**整门课的班级与名单**打成一个 zip 导出 / 导入 / 下模板） | `/teacher/classes`（老地址 `/teacher/scores`、`/teacher/rollcall` 自动跳转） |
| 课程管理（只管课程级别的东西：多课程、**按学期分组**、**复制课程**（本地 fork）、**课程包导出 / 导入**（可只带方案/名单/内容）、下载空壳模板；整体替换时旧文件进 data/.trash/ 可捞回，导出前先体检体积与超大文件。**内容文件不在这里编辑** —— 去各自的 tab 里导） | `/teacher/courses` |
| 模块（课堂作业 / 期末机试 / 大作业 / 以后新加的） | `/teacher/modules/<考核项>`、`/student/modules/<考核项>` |
| 作业库（**课堂作业 / 大作业两套设计**：题目 + 起手代码 / 题目 + 附件要求；新建作业时从目录选或直接上传设计包；截止时间、只保留最新提交、批阅进度） | 课堂作业页 / 大作业页 →「作业目录」 |
| 考核方案（考核项、分值、计分规则、模块开关） | `/teacher/scheme` |
| 代码练习 | `/teacher/playground`、`/student/playground` |

## 从零开始（新部署 / 新开一门课）

每一步都有模板，不用猜格式：

| # | 做什么 | 在哪儿 | 拿模板 |
|---|---|---|---|
| 1 | 建课 | 课程管理 → ＋新建课程（填名称 / id / 学期） | 或「下载模板」要一个空壳课程包，改完导回来 |
| 2 | 配班级与名单 | 班级管理 → **班级与名单** → 下载模板 → 填好各班名单 → 压缩成 zip → 导入 | `classes/示例班级.roster.csv` + README（一个 csv = 一个班，文件名就是班名） |
| 3 | 放讲义与材料 | 讲义页 → **模板** → 改完导回；或直接「导入讲义」 | `第01课-课程标题.md` + README（按《小节锚点约定》：`第NN课-标题.md` 命名、讲义 `##`+`### 📺 屏幕`/`### 🎤 讲稿`+`####` 细节、材料 `##`+`###`、两侧同名即配对） |
| 4 | 放代码示例 | 代码练习页 → **模板** | `第01课-示例标题/{index.html,main.js,style.css}` + README（一个目录 = 一课；README 里写了第 02~11 课的 Vue SFC 结构、一课多页、练习型 `qN.js`、分发注意事项） |
| 5 | 出机试卷 | 期末机试页 → **模板**，或页面里「＋新建机试」图形化出题 | `试卷模板.json` + README（字段见《机试试卷格式规范.md》） |
| 6 | 定考核方案 | 考核方案页（分值、规则、模块开关）；方案也能单独导出 / 导入 | 课程包里的 `scheme.json`（见《课程包格式规范.md》第 3 节） |

模板全部按课程资料的三方职能约定写：讲义是**教师讲稿**（含 📺 屏幕 / 🎤 讲稿配对），材料是**学生讲义**（含 ✅ 自测 / 📚 拓展 / 🧪 配套代码，不写任何教师向内容），
示例与讲义材料**同名同号**。改完讲义/材料跑一次 `cd 课堂系统 && node server/check-sections.js` 自证两侧小节对齐（错误 0 即合格）。
`代码练习` 的在线工作台目前只支持 Vue 那一套（纯静态 HTML/JS/CSS 也可以），React / 打包工程 / 其他语言暂不支持 —— 那些课的内容仍可放进 `代码示例/`，只是不能在线编辑预览。

整门课要搬到另一台机器：课程管理 →「导出课程包」（可只勾方案/名单/内容），另一台「导入课程包」。
只想更新某一栏（比如换一批讲义）：去对应的 tab 点「导入」，先看报告再落盘。
学生端菜单开哪几项：侧栏每个模块项右边的**小眼睛**，随时点，不写进方案、不影响计分。

作业这块分成两套规范，别混：

- 课堂作业：《课堂作业规范与提交约定.md》—— 学生交 **代码**（整份、只留最新），老师**在线看代码与渲染**后给等级 + 评语
- 大作业：《大作业规范与提交约定.md》—— 学生交 **附件（zip / pdf / md / png / mp4 / pptx）+ 说明 + 链接**，老师下载附件按量规打分
- 两者都在「作业目录」里放着可复用的**设计包**；建作业 = 从库里挑一个（复制代码到作业自己名下），改/删设计都不影响已建的作业

**侧栏底部是两级切换**：`课程` → `班级`。
 侧栏菜单里每个模块项右边有个**小眼睛**：点一下就把这个入口从学生端菜单里收起 / 放出来（考核方案页每个考核项右边也有同一个眼睛，两处状态同步；它不写进方案，所以不动方案版本、不影响计分）。切课程换讲义/材料/方案/模块；切班级换计分、考勤、互动、名单页里正在看的那一班（选择记在本地，刷新/换页都记得）。班级列表跟着课程走 —— 不同课程有不同班级，不会串。

**目录关系（解耦后）**：

```
<任意位置>/
   classroom-system/    ← 本系统（server / web / tools / data），整个目录可以单独拷走
   course-content/      ← 课程内容（lecture / materials / 代码示例），系统只读它
```

系统按这个顺序找内容目录，谁先命中用谁：

1. 环境变量 `TS_COURSE_DIR`
2. `data/config.json` 里的 `courseDir`（相对系统目录解析，默认 `../course-content`）
3. 系统目录上一级的 `course-content/`
4. 系统目录上一级本身（离线包布局：`lecture/ materials/ 代码示例/` 与系统目录平级）
5. 系统目录下的 `content/`

> 内容**不搬家**：`materials/` `lecture/` `代码示例/` 原地被读取，改完文件刷新页面即生效；
> 系统里不复制任何课程资料（避免两份内容不同步）。内容目录缺失时服务照常启动，只在控制台提示怎么配。
> 旧版的离线工具（mdReader / 名单抽取器 / 机房投屏 / 积分系统）已全部并入本系统并删除，不再维护。

## 1. 快速开始

> **部署形态**：后端跑在**服务器**上（Node ≥ 20 LTS）；教师机与学生机只开**浏览器**。
> **Win7 已不支持**：便携 Node 13 那条离线包路线已下线，服务端按现代 Node 写。
> 浏览器下限是 **Chrome 109** —— 这是机房现有设备的底线，不是 Win7 的遗留要求；
> 机房整体换代后，可以把这个下限和 `build.target` 一起上调（见 §「兼容体检」）。
> 入口页自带兼容性检测：缺能力直接给兜底提示页（含绿色版 Chrome 下载按钮），版本偏低挂一条可关闭的提示条 —— 见 `服务器部署.md`「浏览器要求与兼容性兜底页」。
> 服务器部署（systemd / NSSM / Nginx / HTTPS / 备份 / 升级 / 监控）见 **`服务器部署.md`**。

### 服务器（一次性）

1. 装 **Node.js ≥ 18 LTS**（20 / 22 都行）。服务端零第三方依赖，不用 `npm install`。
2. 首次启动会自动生成 `data/config.json`：
   ```bash
   sudo mkdir -p /var/lib/classroom/data
   sudo TS_DATA_DIR=/var/lib/classroom/data node server/index.js
   ```
3. 改 `config.json`：`teacherPassword`（**必改**）、`secret`（首次自动生成，别清空）、`courseDir`（课程内容位置）。
4. 用 systemd / NSSM 托管（`服务器部署.md` §4 / §5），前面挂 Nginx 上 HTTPS（§6 / §7）。
5. 学生端地址形如 `https://classroom.example.edu/`；机房只要能打开这个网址。

### 教师机 / 学生机（零安装）

- **教师端**：把 `打开教师端.bat` 拷到教师机，用记事本打开，把里面 `EDIT HERE` 那段的 `BASE_URL` 改成服务器地址（脚本不生成任何文件）
  （如 `http://192.0.2.10:18730`），之后双击 `.bat` 即可。它会探活、挑浏览器、并用白名单启动 Chrome，
  让**纯 http 下「开始投屏」也能用**（详见 `服务器部署.md` §7）
- **学生端**：浏览器打开 `<服务器地址>/` → 选课程 + 学号 + 姓名，不需要任何参数
- 也可以直接 `https://<服务器>/teacher/lecture` 用普通浏览器打开 —— 那样只有 https 才能投屏

### 每节课

1. 服务器上的服务常驻（systemd / NSSM 自启，不用每次点）。
2. 教师端打开 `/teacher/lecture` → 侧栏底部 **开始投屏** → 选择「整个屏幕」。
3. 学生打开 `https://<服务器>/` → 选课程 + 学号 + 姓名登录。
4. 老师点开始时，学生端**自己弹出投屏页** `/watch`，不用喊「点左侧课堂投屏」。
   浏览器拦弹窗时（下面 §7 有解释），页面底部会出现一条红色横幅「老师开始投屏了」，点一下即可，一节课只需点这一次。

### 开发调试（改前端时用）

双击 **`开发调试.bat`**：一个窗口起后端（`node server/index.js`，18730），一个窗口起 vite dev（5173，带 HMR），然后自动打开浏览器。端口已被占用时那一半会跳过，不会报 EADDRINUSE。

```
前端  http://127.0.0.1:5173     ← 改 web/src 里的文件，保存即生效
后端  http://127.0.0.1:18730    ← vite 已把 /api /examples /uploads /ws 代理过去
```

dev 模式会报 Vue 的告警（未解析组件、缺 prop、插槽名写错…），这些在生产构建里看不到，所以改完组件建议在这个模式下过一遍页面。**dev 看到的效果不等于发布**：上线前仍要 `npm run build`（产出 `web/dist`，后端托管的就是它）。

### 前端改动后重新构建

服务端零依赖、不用构建；只有 `web/` 需要构建一次：

```bash
cd web
npm install
npm run build
```

> 构建产物 `web/dist/` 由 Node 直接托管。**其余机器不需要装任何东西**，浏览器打开网址即可。
> 服务器端依赖只有 `yauzl`（流式解课程包 zip）与 `exceljs`（读 xlsx 名单），`npm install` 一次即可；学生机 / 教师机仍然零安装。
> 构建目标与基线对齐在 `chrome109`（早先是 chrome78 —— 但 CSS 早就要求 84/108，留着是自欺）；
> `node tools/check-compat.mjs` 会同时校验「服务器 Node ≥ 20」与「前端不越 Chrome 109」两条基线。

## 2. 角色与页面

### 教师端

| 页面 | 路径 | 说明 |
|---|---|---|
| 讲义 | `/teacher/lecture` | 读 `lecture/*.md`；**讲义 / 课程材料** 两种视图一键对照（切视图不影响「跟随」，学生端照旧按小节跳）；字号可调；页头「导出 / 导入讲义（课程材料）」只打包该目录 |
| 投屏设置 | `/teacher/screen` | 档位（跟随设备屏幕 / 跟随窗口 / 固定档）与实时状态；入口在侧栏底部的「投屏设置 →」，**开关同样在侧栏底部，全站常驻，切页面不断流** |
| 班级管理 | `/teacher/classes` | **名单与分数在一页，但只读分**：班级增删改、**名单模板下载 / 导入（xlsx / csv 由服务端解析、也可粘贴；逐行报错；先干跑出「新增·改名·移出」报告，确认后才写）**、**单个添加 / 编辑 / 删除学生**、「班级名单」页签（**点表头排序 + 按关键字 / 状态 / 投屏 / 总评 / 加分筛选**，表头右上是「＋ 添加学生」「导出总评」）、「全班流水」页签（按项 / 关键字筛，右上「导出流水」）；点一行看学生明细（各项分 + 流水，**只读**）。**这里不记分、不点名**：记分在各模块页与考勤 / 互动页做，撤销也在那边 |
| 代码练习 | `/teacher/playground` | 改代码看页面，CodeMirror 编辑器 + 按页面分组的文件树（双端共用，见下文）；页头「导出 / 导入代码练习」整目录搬运 `代码示例/` |
| 课堂作业 | `/teacher/modules/homework` | 从**作业目录**选设计 / 上传设计包 / 空白新建（作业自带起手代码，不绑代码示例），可设**截止时间**；开始收 → 按时间看提交 → **左侧只读看代码、右侧直接看渲染**后打等级 + 评语；顶部有已交/已批/未交进度（见《课堂作业规范与提交约定.md》） |
| 模块（课堂作业 / 大作业 / 以后新加的） | `/teacher/modules/<考核项>` | 一套页面服务所有模块：布置 → **开始收 / 截止** → 按时间看提交 → 按该考核项的规则批阅（见下文） |
| 大作业 | `/teacher/modules/project` | 同样从**作业目录**选设计（只有 `project.json`，没有代码）；学生交附件（必填）+ 说明 + 链接（可选，可在设计里改），只保留最新；批阅时下载附件、传评分证据（见《大作业规范与提交约定.md》） |
| 考核方案 | `/teacher/scheme` | 可视化改方案：增删考核项、调分值、选规则并填参数、开关模块、**试算对比**、变更日志、结课归档（见下文）。**加一项考核 = 自动多一个模块入口** |

> 侧栏分三栏（可按「讲课 / 考核 / 管理」看，也能折叠成图标条）：
>
> | 栏 | 内容 | 为什么这么分 |
> |---|---|---|
> | 讲课 | 讲义 · 代码练习 | 上课第一件事是「讲一节、点一个」 |
> | 考核 | 方案里开的模块（考勤点名 / 课堂互动 / 课堂作业 / 机试 / 大作业…） | 边上课边记的那一叠，模块开关由方案决定 |
> | 管理 | 班级管理 · 课程管理 · 考核方案 · 投屏设置 | 课前课后才动的配置 |
>
> 投屏开关在侧栏底部，全站常驻，切页面不断流。
>
> **学生端用同一套分组与顺序**，学生没有的项自动跳过：
>
> | 栏 | 学生端内容 |
> |---|---|
> | 讲课 | 课程材料（对应老师的讲义）· 代码练习 |
> | 考核 | 方案里启用的模块（考勤 / 课堂互动只有老师端，自动不出现） |
> | 管理 | 我的分数 · 课堂投屏 |
>
> 老师还能在「考核方案 → 某个模块 → 模块」里单独关掉 **「学生端也显示这个入口」**：
> 关掉后学生菜单里没有这一项，直接输地址也会被挡（提示「这一项老师暂时没在学生端开放」）。
>
> 侧栏顶部的系统名称下面是**作息时钟**，短一行：`周四 20:58 · 已下课`（有课时 `周四 10:30 · 第3节`）。
> **「第几节」由服务器按作息表算**（机房机器时间未必准，而节次直接影响几点算迟到），
> 考勤页进来时也会默认落在当前这一档（如 `3-4节`）。
>
> 侧栏是三段固定结构：**品牌行（名称 + 时钟）固定** · **讲课 / 考核 / 管理这一叠可滚动** · **脚部（课程 / 班级 / 开始投屏 / 退出登录）固定**。
>
> 作息表默认就是示例职业学院那张（冬春季 / 夏秋季两套，各 10 节）。改法：`data/config.json` 里加
> `timetable`（不改则用内置默认；夏秋季默认按 `05-01 ~ 10-31` 判定）：
>
> ```jsonc
> "timetable": {
>   "title": "示例职业学院作息时间表",
>   "summer": { "from": "05-01", "to": "10-31" },
>   "periods": {
>     "winter": [["08:10","08:55"], ["09:05","09:50"], ["10:10","10:55"], ["11:05","11:50"],
>                ["14:10","14:55"], ["15:05","15:50"], ["16:00","16:45"], ["16:55","17:40"],
>                ["19:00","19:45"], ["19:55","20:40"]],
>     "summer": [ …同样 10 段，改成夏季作息… ]
>   }
> }
> ```
> 老链接 `/teacher/scores`、`/teacher/rollcall` 都会跳到「班级管理」；点名与随机抽人在「考勤点名」「课堂互动」两个模块页里。

### 学生端

| 页面 | 路径 | 说明 |
|---|---|---|
| 课程材料 | `/student/materials` | 读 `materials/*.md`，上一课 / 下一课、搜索、字号 |
| 课堂作业 | `/student/assignments` | 老师布置了哪些作业、自己交了没 / 几分；`/student/assignments/<id>` 是做题页 |
| 模块（课堂作业 / 大作业 / …） | `/student/modules/<考核项>` | 交代码的进做题页，交材料的进提交页；方案里没启用的模块不显示入口 |
| 我的分数 | `/student/score` | 五个计分项 + 加分、总评、班级排名、每条记录的原因与时间 |
| 投屏观看 | `/watch` | **必须登录**（未登录会跳登录页并带回本页）；不套布局，kiosk 全屏友好；默认 1:1 像素、可缩放（见下） |
| 代码练习 | `/student/playground` | 与教师端同一套 |

**投屏页按原尺寸显示，不跟着窗口缩放**：老师机 1920×1080 那点小字，硬塞进学生机 1366×768 会缩成看不清，
所以默认 1:1（像素对齐、字最清楚），画面放不下就**出滚动条**让你自己拖。要看全貌或凑近看代码，用底部那排工具：

| 操作 | 快捷键 | 说明 |
|---|---|---|
| `＋` / `－` | `+` / `-` | 放大 / 缩小一档（20%–400%） |
| 适应窗口 | `0` | 整张画面塞进窗口（看清楚版式用） |
| 实际大小 | `1` | 回到 100%（看清楚文字用） |
| 全屏 | `f` | 隐藏浏览器边框 |
| 双击画面 | — | 100% ⇄ 适应窗口 来回切 |

只有 `Ctrl` + 滚轮（mac 上 `⌘` + 滚轮）才缩放；普通滚轮就是上下滚动、`Shift` 滚轮左右滚动。
缩放倍率存在本机（`localStorage`），换课时不用每次重调。

### 登录规则

- **教师**：口令（`data/config.json`）。
- **学生**：班级 + 学号 + 姓名，与名单比对通过即登录，**免密码**——机房上课不排队。
- 学生令牌里锁死 `classId + sid`，`/api/student/score` 不接受前端传 sid，所以**看不到别人的分**；写操作全部服务端校验 `teacher` 角色。
- 讲义接口对 `lecture` 类型强制教师角色：学生拿不到讲稿（教学法不外泄）。

### 跟随讲义（讲课主用法）

老师翻讲义，学生端「课程材料」自动跳到对应小节 —— 不用投屏也能把全班带到同一页。

- **节点怎么对应**：**两侧标题写成同一个就是同一节点**，不加任何标记（规范见 `../小节锚点约定.md`）。
  判定时忽略空白 / 冒号 / 括号形状 / 行内标记 / 英文大小写，其余必须逐字一致。
- **支持多级**：`##` 是大块，`### / ####` 是它的细节点（讲义里写在 `### 📺 屏幕` 之内）。
  **层级不参与匹配** —— 讲义 `####` 对材料 `###`，标题一样就算同一个节点。
  讲义里带 `### 📺 屏幕` 的节才参与同步；对不上的节点**不推送**（宁可不跳，也不跳错），
  讲义页会提示「本节点未同步：材料里没有同名标题（最接近「…」）」。
- **一节一屏（软约束）**：最小叶子节点建议 ≤900 字 / ≤3 个代码块。超了就在两侧同时下沉一级拆开，
  拆到位之后跟随才真正"细到一屏"。校验脚本会把超标的节点排序列出来。
- **推送粒度**：默认「按位置」—— 除了节，还推**节内进度**（滚到这一节的百分之几），
  所以一节跨好几屏时学生也能逐步跟上，不会只在换节时才跳。讲义页那个「按位置 / 按节」按钮可以切回只按节。
  换节必推；同一节内进度变化 ≥1% 才推（滚动停止 160ms 后判定），不会刷屏。
- **学生端表现**：自动切到对应课、平滑滚到同一位置、标题闪一下，底部提示「跟着老师跳到「…」」。
  页面上有「跟随中 · 小节标题」标记。
- **不打扰**：学生自己往回看时不会被反复拽回 —— 只有偏离超过**一屏**、或老师换到下一节时才纠正。
- **临时不跟随**：讲义页右上角的「跟随中 / 已暂停」按钮，暂停后学生端不再跟着动。
- **中途进来的学生**：打开页面时拉一次 `/api/follow`，直接对齐老师当前所在的小节。

### 评分表：排序与筛选

**点表头排序**：学号 / 姓名 / 状态 / 投屏 / 五个计分项 / 加分 / 总评，每列都能排；点一下升序（`▲`），
再点同一列换降序（`▼`）。**默认是学号升序**，并列时固定按学号收尾——分数一样的人不会每 8 秒刷新就换位置。
学号用 `numeric` 比较，`...003` 排在 `...010` 前面，不会被字符串序坑。

**筛选**（跟排序互不影响，可以叠加）：

| 控件 | 选项 |
|---|---|
| 关键字 | 搜姓名 / 学号 |
| 状态 | 全部 / 只看在线 / 只看离线 |
| 投屏 | 全部 / 只看在看 |
| 总评 | 全部 / 及格（≥60）/ 不及格（<60） |
| 加分 | 全部 / 只看有加分 |

右侧显示「筛出 n / 总 m 人」；有筛选条件时出现「清除筛选」，一键回到全班。
排序和筛选都**只在浏览器里做**，切换列不会重新请求服务端，讲授时随便点。

### 两个状态列：登录在线 / 正在看投屏

班级管理页的学生表有两列状态，都只用来「看」，不参与点名、考勤、计分：

| 列 | 含义 | 判定 |
|---|---|---|
| **状态**（登录中） | 学生是否开着学生端 | 心跳 + 在场通道 |
| **投屏**（在看） | 学生是否正在收投屏画面 | `/watch` 带着学生令牌连上、且教师正在投屏 |

「在看」只在教师真正开播时点亮点 —— 学生开着观看页但老师没开播，只是等着，不算在看。
学生机没登录过学生端时无法对应到人（匿名观看），只计入教师端的「在线学生」总数。

登录在线的判定：学生用自己的学号登录即**在线**；关掉页面或退出登录后变回**离线**。

| 情况 | 判定 | 依据 |
|---|---|---|
| 登录着（含切到别的窗口/标签页） | **在线** | WebSocket 在场通道；切后台不算离开 |
| 点「退出登录」 | 立即离线 | 前端报离 |
| 关标签页 / 关浏览器 / 断电 | 约 5 秒后离线 | WS 连接断开（强杀浏览器时 `pagehide` 不触发，只能靠 TCP） |
| 拔网线等极端情况 | ≤2 分钟离线 | HTTP 心跳超时兜底 |

**它只用于「此刻谁开着页面」的显示，不参与点名、考勤、计分**：
点名页仍是随机抽人 + 抽中后手记「到 / 迟 / 早 / 缺 / 假」，考勤分数一律由老师确认后落库。
这条边界是刻意的——状态是瞬时信号（会误判、会断网），分数是要写进总评的账，两者不能混。

### 代码练习（改代码 → 立刻看页面）

教师端 `/teacher/playground` 与学生端 `/student/playground` 是**同一个页面**，三栏：文件树 | 编辑器 | 预览。
读的是 `代码示例/` 里的真实文件，改动**不写服务器、不联网**——它存在同学自己那台机器的浏览器里（见下文「改动存在哪」）。

**文件树按页面分组**，一组 = 一个 HTML 页面 + 它的入口 + 入口 `import` 链上的源码：

| 线索 | 说明 |
|---|---|
| 页面自己引的 | `<script src>` / `<link href>`（含 `judge.css` 这类不带 `./` 的同目录写法） |
| 入口 | `sfc-boot.js` 的 `data-entry` → 第一个 `<script type="module">` → 同名 `.mjs/.js` |
| import 链 | 从入口递归 `import` / `export … from` / `import()`，认 `@/` 别名，省略扩展名与 `/index.*` 自动补 |
| 同名孪生 | `q3.html` ↔ `q3.js`、`lab.html` ↔ `lab.mjs` |

被多页共用的文件收进「多页共用」组，谁都没引用的收进「未被页面引用」组；「全部」勾选框临时放出页面与入口文件（纯 HTML 课没源码，不勾也能点组标题直接看页面源码）。

**右侧报错面板**：预览里出错不再只显示一行 `error`，而是分类型列出（错误类型 / Promise / console / **编译** / 资源），每条带**文件名 + 第几行第几列**、可折叠的调用栈，以及「**跳到第 N 行**」按钮（直接跳回编辑器对应行）；支持「复制」整份报错、「清空」。重跑时自动清空，同一条错误不会重复刷屏。

运行（含自动运行）不会把右侧画面弹回顶部：同一个页面重跑会记住滚动位置，只有切到别的页面才从顶部开始。

**编辑器是 CodeMirror 6**（本地打包，不走 CDN）：行号、代码折叠、括号匹配、自动补全（不自动弹）、`Ctrl+F` 搜索、缩进 2 空格、One Dark 主题。
`Ctrl+S` / `Ctrl+Enter` 立即运行；`Ctrl+滚轮` 或工具栏 `A−/A+` 调字号（11–24，记忆在浏览器）。

**排版**：代码块与渲染结果**占满整个内容区**（头部固定，不再留半屏空白）。页头两个按钮 + 中间那条缝：

| 操作 | 效果 |
|---|---|
| 「上下排 / 左右排」 | 左右并排 ↔ 上下叠放 |
| 拖动那条缝 | **按住不放可以一路拖**：往左到底＝收起代码 → 往右回中间＝左右排（20% 一挡）→ 再往右到底＝上下排 → 往左又回左右排。不用松手重点 |
| 代码收起后 | 左边留一条抓手，按住往右拖就把代码块拉回来 |
| 上下排时 | 分栏条贴在代码块右边框外侧的**12px 槽里**（与代码块等高，不压住代码区滚动条），往左拖就切回左右排；两块**各占 78vh（最小 520px）**，不再显得扁；**滚动留在内容区里**（整页高度仍锁一屏，头部不会因为出现滚动条而回缩） |
| 「隐藏代码 / 显示代码」 | 常驻按钮，两种排列都能用 |
| 宽度 | 工作台不吃 .content 的 1520px 限宽，**整屏铺满**（右侧不留空） |
| 滚动条 | 代码区滚动条改成 10px 细圆角、悬停变亮，深色主题下不再突兀 |

三个状态（排列方式、占比、是否隐藏）**不记忆**：学生拖乱了、或者拖成不认识的布局时，**刷新页面就回到默认**（左右排 · **代码 60%** / 预览 40% · 代码可见）；换页面再回来也是默认。

**老师可以「同步代码」**（教师端页头那个按钮，只在代码练习页出现）：

| | 行为 |
|---|---|
| 老师点「同步代码」 | 当前**这一课 + 这个文件 + 右侧预览页 + 内容**推给全班；之后每次改动（停手 0.5 秒）继续推 |
| 老师换课 / 换文件 / 换预览页 | 学生跟着跳：「课」切过去、「文件」选上、右侧画面也换成同一页 |
| 老师光标移动 | 学生端光标跟到同一位置，并自动滚到那一行（内容没变时不重设文档，不闪） |
| 学生端 | 自动切到同一课、同一文件，编辑器**只读**，顶部一条提示；**没有退出开关**（换课 / 换文件两个下拉也禁用）——老师同步必须跟 |
| 老师点「停止同步」 | 全班回到**自己原来的代码**（开始跟随前的版本，含停在哪一课哪个文件） |
| 老师忘点停止 | 30 分钟没有新推送就自动结束（避免学生一直只读） |

学生的代码从头到尾都只在本机浏览器里，同步只是「把你这一版推到学生屏幕上」；中途学生自己改的不会丢——开始跟随时先暂存一份，停止时原样恢复。

**预览**：

- 点文件树里的页面 → 预览切到该页；点源码 → 预览切到「用它的那个页面」，改完立刻能看见效果（0.7 秒防抖，`自动运行` 可关）。
- iframe 里抛的错误会以红条回流到预览上方，不用开控制台。
- `↺ 还原（n）` 把改过的文件退回源文件，红点与计数如实显示脏文件数。
- **第 12 课起的 npm 工程**（含第 17 课三个子项目）浏览器里没有打包器与 `node_modules`，给的是说明卡（入口在哪、去 `代码示例/<课>` 跑 `npm install` + `npm run dev`），不是白屏；源码照样能看能改。

**改动存在哪（刷新 / 关浏览器都不丢）**：

改完 0.4 秒，内容就写进这台机器的 `localStorage`，按「**谁** + **哪一课**」分桶：

| 项 | 说明 |
|---|---|
| 键 | `pg-edits:<身份>:<课程目录>`，如 `pg-edits:s-c00b8…-2025010199:第05课-响应式基础下` |
| 身份 | 老师是 `t`，学生是 `s-<classId>-<sid>`。**机房共用一台电脑也不串**，换人登录看到的是自己的那份 |
| 内容 | 只存「被改过的文件」，值是整份文本；改回原样等于没改，会自动从存档里删掉 |
| 恢复 | 打开页面 / 切课时回填（只认当前示例包里真有的文件，旧存档不会串进新版本），脏文件照样打红点、`↺ 还原` 照样算得出 |
| 落地时机 | 打字后 0.4 秒防抖；另在切课、切标签页、关页面时强制落一次，防抖窗口内的最后几个字也不会丢 |
| 清掉 | 文件面板底部「清空」（只清当前这一课，会二次确认）；`↺ 还原` 也会把存档一起清掉，否则下次打开又"复活" |
| 容量 | 浏览器给每站约 5MB 总配额。真存不下时面板底部会变成「本机存不下（浏览器配额满或被禁），只在本页有效」——**编辑和预览照常可用**，只是这一课不落盘 |

> 边界：这是**本机浏览器**的缓存，不是云端。换电脑、换浏览器、清浏览器数据、无痕窗口，都会回到原始示例。要留档请另存文件（`Ctrl+A` 复制走或另开一份）。

实现：分组逻辑 `web/src/utils/pgTree.js`（纯函数）、编辑器封装 `web/src/utils/pgEditor.js`、页面 `web/src/views/Playground.vue`。

### 课堂作业（布置 → 交 → 批）

一节课的标准动作：**老师建作业 → 点开始 → 学生改代码点提交 → 老师按时间顺序一条条看、顺手给分**。

| 谁 | 做什么 | 在哪 |
|---|---|---|
| 老师 | 「＋新建作业」：选一课（`代码示例/` 里的目录）+ 标题 + 说明。**新建一律是「未开始」** | `/teacher/assignments` |
| 老师 | 「▶ 开始作业」：学生立刻能交（已开着的学生端会自动刷新，不用喊 F5）；「■ 结束作业」：停止收卷 | 同上 |
| 学生 | 点作业卡进做题页：**就是 代码练习**（同一套文件树 / 编辑器 / 预览），右上多一个「提交」 | `/student/assignments/<id>` |
| 老师 | 提交记录**按交的时间正序**排（谁先交谁在上），点一行看代码 + 打分，`保存并下一条` 一路批下去 | 同上 |
| 谁 | 未交名单跟着班级筛选走（讲评时顺手点名） | 同上 |

**默认不开始，卡在两处**：学生端列表里「未开始」的卡片只有灰字「等老师开始」，没有入口；
即使手敲 `/student/assignments/<id>`，页面也只显示「老师还没开始」；真去 POST 提交，服务端照样 403。
开始 / 结束都记时间（`openedAt` / `closedAt`），结束之后已交的照样能看到、能批。

**学生交的是「整份」，不是只有改过的那几个**：提交时把这个作业桶里**全部**文件的当前内容 POST 上去
（改过的取改动，没动过的取原文，一整课也就几十 KB），`changed` 单独记一份。
这样老师拿到手就是一套能直接跑起来的工程，不用回原始示例里拼 —— 学生改完的样子老师当场就能看见。
弹层里代码面板默认只列改过的那几个（`只看改过的` 勾着），勾掉就看全份：
一眼看出「动了什么、就动了这么点」，又随时能翻上下文。
重交不覆盖，每次都是一条新记录（老师能看到改到第几版）。
改动在本机的键是 `pg-edits:hw-<作业id>:<课程目录>`，所以**这次作业的改动**跟 代码练习 里那课的改动、
以及别的作业的改动互不干扰。

**老师端那一屏**：

- 顶部一条作业切换条（带 `●`/`○` 状态灯 + 应交人数），下面是控制台与五个数字：应交 / 已交 / 提交条数 / 已批 / 未交。
- 列表每 8 秒自动拉一次（页面在后台时不拉），刚交上来的那条标「新」；学生交作业走的是学生端的通知通道，
  老师端靠轮询兜住，不用手动刷新。
- 审阅弹层左边是**只读的 CodeMirror**（`readOnly` + `editable:false`，能选中、能 `Ctrl+F`、能折叠，但改不动学生的代码），
  右边是**跑起来的页面**：默认打开 `index.html`，可以在下拉里换页、点「运行」重跑，页面报错会以红条回流。
  渲染和 代码练习 是同一套做法（`utils/pgPreview.js`：页面里的 `<script src>` / `<link>` / `.vue` 由
  `srcdoc.js` 就地内联，其余资源按 `<base>` 回 `/examples/<课目录>/` 取），所以**学生看到的和老师看到的是一个东西**。
- 渲染的是学生的代码，所以 iframe 带 `sandbox`（**不给 `allow-same-origin`**）：它跑在独立源里，
  拿不到教师端的令牌和 localStorage。代价是没有 localStorage 的示例在预览里用不了存储 API —— 比拿到令牌值。
- 打分在弹层底部：`分数` + `评语`（学生看得到），`保存并下一条` 保存后自动翻到下一个；`清掉分数` 把分改回「待批」。
  批阅就是记分：判 **A / B / C / X**（可勾迟交 ×0.5）→ 自动写一条「课堂作业」记分事件（均分折算 20 分），改判会先撤掉上一次那条账。相应地，**班级管理里不再给「课堂作业」记分入口**，只显示「去模块评分」。
- 第 12 课起的 npm 工程在浏览器里仍然跑不起来（没有打包器），弹层里给说明卡，代码照看。

### 大作业（课程项目）

跟课堂作业**共用 `assignments` / `submissions` 两张表**（靠 `kind` 分开），但交的东西不一样：

| | 课堂作业 `kind=work` | 大作业 `kind=project` |
|---|---|---|
| 绑哪一课 | 必须选一个 `代码示例/` 目录 | 不绑课，学生交自己的项目 |
| 学生交什么 | 那一课的**整份代码**（在 代码练习 里改） | **说明 + 部署/仓库链接 + 附件**（源码包 / 截图 / PDF） |
| 落在哪 | `students/<班级>/<学号>/作业/<作业>/<提交>/` | `students/<班级>/<学号>/大作业/<作业>/<提交>/` |
| 老师怎么批 | 左边看代码、右边跑渲染 → 判等级 A/B/C/X | 左边看说明/链接/附件（可下载）→ 四维量规（12/9/6/3）合计 30 |

- 学生端入口是**独立的一页**：`/student/projects`（列表）→ `/student/projects/<id>`（提交页）。
  表单三样都能空两样：说明、链接、附件至少给一项；单文件 ≤6MB、最多 6 个，重交不覆盖。
- 附件是**二进制**：前端读成 dataURL 传，服务端写 `students/…/大作业/<作业 id>/<提交 id>/<原文件名>`，
  同名文件自动加序号。
- 下载走 `GET /api/files/project/<作业>/<提交>/<文件名>`：老师随时能下，学生只能下**自己那份**。
  页面上用 `download()`（fetch + blob）而不是 `<a href>` —— 裸链接带不上 Bearer 令牌。
- 批阅就是记分：四维合计 → 自动写一条「大作业」记分事件（30 分制），改判先撤旧账。
  所以**班级管理里不再给「大作业」记分入口**，只留「去模块评分」的链接。
- 老师端的证据上传仍走 `data/uploads/`（历史行为，`/uploads/` 无鉴权），学生的大作业附件才进学生目录。

### 考核方案与计分规则（可配置）

**考核方案是数据，不是代码**：`data/schemes/example-course.json` 里写着有哪些考核项、每项多少分、
用哪条规则、规则参数是什么、哪一项有对应模块。改这个文件 → **保存即生效**（按 mtime 热加载，不用重启），
刷新页面评分表列、满分、模块入口都跟着变。

```jsonc
{
  "id": "example-course", "name": "示例课程", "version": 1,
  "totalFull": 100, "passLine": 60, "cap": 100,
  "items": [
    { "key": "homework", "name": "课堂作业", "full": 20, "form": "graded",
      "rule": { "type": "avg", "params": { "grades": [...], "lateFactor": 0.5, "skipWorst": 0 } },
      "module": { "enabled": true, "title": "课堂作业", "submit": "code" } }
  ]
}
```

| 字段 | 作用 |
|---|---|
| `full` | 本项满分（决定评分表列头与折算） |
| `extra` | 是否加分项（不进 100 封顶） |
| `rule.type` + `params` | 用哪条规则、参数怎么填（见下表） |
| `form` | 采集形态：`attendance` / `manual` / `graded` / `rubric` / `paper`（自评互评不做） | |
| `module.enabled` | 这一项有没有对应的模块（`true` 才会出现在导航与入口里） |
| `module.submit` | 模块里交什么：`code`（代码工作台）或 `files`（说明 + 链接 + 附件） |

**规则库**（`api/src/lib/rules.js` 的 `RULES`，老师只调参数，不写公式）：

| type | 参数 | 用途 |
|---|---|---|
| `base` | `start`、`perAbsent`（缺勤每次扣）、`perLate`（迟到/早退每次扣）、`floor`、`zeroRule{kind,count,lateMerge}` | 考勤：起始分往下扣，**缺勤一次扣几分可配**，缺勤满 N 次归零；改参数会重算历史记录 |
| `acc` | `start`、`perHitMax` | 互动 / 加分：从 0 累加封顶 |
| `avg` | `grades[{key,label,factor}]`、`lateFactor`、`skipWorst` + **每次记录自带的 `weight`** | 课堂作业 / 报告：多次评定按**每次权重**加权平均（权重缺省 1 = 简单平均），可迟交折算、可去最差。权重在布置作业时设（如期末综合 2、随堂小练 0.5） |
| `last` | `grades`、`lateFactor` | 终稿类：只认最后一次评定 |
| `raw` | `rawFull`、`factor` | 机试 / 笔试：卷面分 × 系数，取最后一次 |
| `rubric` | `dims[{key,name,full 或 weight}]` | 大作业 / 论文：量规逐项相加 |

每条规则都带 `schema`（参数名 / 类型 / 范围 / 说明），方案编辑器照着渲染 —— 以后加规则只写后端一个函数，界面不用改。

### 方案可以单独带走 / 带回来

「考核方案」页右上：**下载方案**（`scheme_<id>_v<版本>.json`）、**导入方案**（选一份 json → 先看差异 → 再选「用文件里的 / 保留本机 / 另存为新方案」）。
跨课程复用、同事之间传一份、下学期换个方案，都不用打整个课程包。

### 改方案：教师端「考核方案」页（不用碰 JSON）

左侧栏「考核方案」→ 左边是考核项列表（合计与总满分对不上会标红），右边是选中项的编辑区：

| 能改什么 | 说明 |
|---|---|
| 考核项 | 加一项 / 删一项 / 上下调顺序；名称、简称、满分 |
| 计分规则 | 下拉选规则，下面**按该规则声明的参数自动出表单**（等级表、迟交系数、去最差、量规维度、卷面满分与系数、考勤归零次数…） |
| 表单提示语 | 项说明（学生/老师在记分表单里看到的提示） |
| 模块 | 开关、导航名称、学生交什么（代码工作台 / 说明+链接+附件） |
| 方案级 | 方案名、总满分、及格线、总评封顶 |

三个配套动作，专门为「随时改」设计：

1. **试算对比**：选一个班，用现有数据把改动前后各算一遍 → 平均分、及格率、变化最大的前 12 人。改错了当场看得见，点「再改改」就退出来（不落盘）。
2. **保存**：版本号 +1，自动追加一条变更日志（谁、何时、改了哪几项，如「课堂作业 满分 20 → 25」）；保存后前端立刻重新拉 `/api/scheme`，导航和评分表同步变。
3. **结课归档**：把「当前方案 + 全班每项得分 + 总评」冻成 `data/archive/<方案>-<班级>-<时间>.{json,csv}`，之后方案再改也不影响这份档；CSV 带 BOM 可直接用 Excel 打开。

接口（都只有教师令牌能调）：

| 方法 | 路径 | 作用 |
|---|---|---|
| `GET` | `/api/teacher/scheme` | 原始方案 JSON + 校验结果 + 规则元数据（schema）+ 形态清单 |
| `PATCH` | `/api/teacher/scheme` | 保存（校验不过 → 400 并列出每条错误；成功 → 版本+1、写变更日志、热加载） |
| `POST` | `/api/teacher/scheme/preview` | 试算对比（不落盘） |
| `POST` | `/api/teacher/scheme/archive` | 结课归档（写 json + csv） |
| `GET` | `/api/scheme` | 解析结果（items + modules），导航/入口/守卫都读它 |

**说明文字是模板（改参数自动同步）**：每个考核项的 `hint` 里可以写 `{变量}`，读取时按**当前参数**渲染 ——
所以老师把「缺勤一次扣 2 分」改成 4 分，说明文字里那句也跟着变，不用手动同步。

```jsonc
{ "key": "attend", "full": 10,
  "hint": "默认全勤 {start} 分；缺勤每次扣 {perAbsent} 分、迟到/早退每次扣 {perLate} 分；缺勤满 {zeroRule.count} 次本项计 0 分。",
  "rule": { "type": "base", "params": { "start": 10, "perAbsent": 2, "perLate": 1,
            "zeroRule": { "kind": "缺勤", "count": 3, "lateMerge": 2 } } } }
```

| 变量 | 含义 |
|---|---|
| `{full}` `{name}` `{short}` `{cap}` | 本项满分 / 名称 / 简称 / 总评封顶 |
| `{start}` `{perAbsent}` `{perLate}` `{floor}` `{zeroRule.count}` `{zeroRule.lateMerge}` | 规则参数（任意层级都能点出来） |
| `{gradesText}` `{latePercent}` `{skipText}` | 等级表文字、迟交百分比、去最差说明 |
| `{dimsText}` `{dimsSum}` `{rawFull}` `{factorPercent}` `{hitText}` | 量规明细与合计、卷面满分、折算百分比、单次上限说明 |

不认识的变量**原样保留**（写错了看得出来）。方案页的「说明」框下面有实时预览和可点插入的变量表。

**模块可用性 = 方案说了算**：`module.enabled` 一关，三处同时消失 —— 侧栏导航（教师端与学生端都读 `/api/scheme` 的 `modules` 生成）、班级管理抽屉里的「去模块评分」入口、以及服务端接口（列表/新建/提交直接 403，`这个模块在考核方案里没有启用`）。所以不会出现「按钮藏了但地址还能进」。

**一个模块 = 一个考核项**（`itemKey` 泛化）：

- 作业/提交/批阅全部挂在 `itemKey` 上，路由是 `/teacher/modules/<itemKey>`、`/student/modules/<itemKey>`（`/student/modules/<itemKey>/<作业id>` 是做题/提交页）。
  老地址 `/teacher/assignments`、`/teacher/projects`、`/student/assignments/<id>`… 全部**重定向**到对应模块，书签不会失效。
- 所以「在方案里加一项考核 + 勾上模块」= **自动多一个模块入口**，不用改代码、不用改路由。
- 页面按 `module.submit` 二选一：`code` → 代码工作台（改代码 + 跑渲染），`files` → 材料表单（说明 + 链接 + 附件）。
- 批阅控件按该项的 `rule.type` 渲染（`components/GradeBox.vue`）：`avg` 给等级 A/B/C/X + 迟交，`rubric` 给维度逐项，`raw` 给卷面分。
  同一个弹层能批作业、大作业、机试，靠的是规则而不是写死的 kind。

### 机试（统一卷 / 题库随机卷）

「期末机试」这一项在方案里默认是开着的（`form: paper`）。老师把一份 **JSON** 交给系统，剩下的事系统做：
校验 → 出卷 → 收答案 → 客观题自动判 → 主观题你判 → 落计分表 → 出答卷文件。

> 规范全文（给老师看的完整版）：**`机试试卷格式规范.md`** —— 字段参考、四种题型判分细则、两种出卷模式、校验规则、常见报错对照都在里面。
> 下面只摘最要紧的部分；模板：`data/exams/_template.json`。

**卷子格式**（模板：`data/exams/_template.json`，也可以直接复制改）：

```jsonc
{
  "kind": "bank",            // bank=题库随机卷；paper=统一卷（全班同一份）
  "title": "期末机试",
  "duration": 90,            // 分钟；不填/0 = 不限时
  "fullScore": 100,          // 可省：默认 = Σ(每段 pick × 每题分)
  "sections": [
    { "id": "choice", "title": "一、选择题", "type": "choice", "score": 5, "pick": 4,
      "questions": [
        { "id": "c1", "stem": "题干", "options": ["A. …", "B. …"], "answer": "A", "explain": "解析（可选）" }
      ] },
    { "id": "short", "title": "四、简答题", "type": "short", "score": 25, "pick": 2,
      "questions": [ { "id": "s1", "stem": "……", "answer": "参考答案（老师判分时看）" } ] }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `kind` | `bank` 每段按 `pick` **随机抽题**（每个学生一份，按「作业 + 学号」定种子，重进还是同一份）；`paper` 全班同一份 |
| `type` | `choice` 选择（答案写选项字母，多选写 `AC`）/ `judge` 判断（`对`/`错`）/ `fill` 填空（可给 `accepts` 多个可接受写法）/ `short` 简答（**不自动判**，留给老师） |
| `score` | 这一段每题多少分；`pick` 抽几道。`fullScore` 与各段合计算不上时导入会给提示 |

**一轮机试的流程**：

1. 教师端「期末机试」→「＋ 新建机试」→「导入试卷 / 题库」选那份 JSON（格式不对会**逐条**告诉你哪段哪题错了）。
2. 点「▶ 开始考试」：学生端立刻能开考并开始计时（题库卷在**开考那一刻**按学生抽卷）。
3. 学生作答：答案 1 秒防抖自动存服务器（换机器、断电都不丢），限时到 0 自动交卷。
4. 学生交卷 → 客观题立刻判完（看到"客观 50 分"这类数字），主观题等你。
5. 老师「看答卷 / 判分」：逐题看学生答案与参考答案，给简答题打分 →「判分并记账」→ **卷面总分自动进计分表**（`卷面分 × 系数`）。
6. 同时在该学生名下生成答卷文件（见下）。

**系统排出四张「纸」**（都像真卷子：卷头、大题分栏、逐题得分、合计，可打印）：

| 什么时候 | 生成什么 | 落在哪 |
|---|---|---|
| 导入试卷时 | `试卷.md/.html`（空白卷）、`答案卷.md/.html`（带参考答案与解析，只给老师） | `data/exams/<作业id>/` |
| 判分之后 | `答卷.md/.html`（这个学生答过的卷子：每题作答 + ✓✗ + 得分 + 参考答案 + 评语） | `data/students/<班级>/<学号>/机试/<作业id>/<提交id>/` |
| 判分之后 | `exam.json`（机器读：卷子 + 答案 + 逐题得分 + 总分 + 时间） | 同上 |

- HTML 是 A4 打印版（宋体、页边距、题目不跨页），浏览器打开 `Ctrl+P` 就是一张卷子；学生也可以自己下载自己那份。
- 题库卷（每人一份）的空白卷是「样例卷」，学生拿到的具体题目在他的答卷里。
- 明细见 `机试试卷格式规范.md` 第 10 节。

接口：

| 方法 | 路径 | 谁 |
|---|---|---|
| `POST` | `/api/teacher/exams/:aid/paper` | 老师：导入试卷 / 题库（校验后存 `data/exams/<作业id>.json`） |
| `GET` | `/api/teacher/exams/:aid` | 老师：试卷摘要 + 每个学生的进度 / 客观分 / 主观分 / 总分 |
| `GET` | `/api/teacher/exams/:aid/submissions/:subId` | 老师：某一份答卷（含学生答案与参考答案） |
| `POST` | `/api/teacher/exams/:aid/submissions/:subId/grade` | 老师：主观题给分 → 总分 → 记账 → 出答卷文件 |
| `POST` | `/api/student/exams/:aid/start` | 学生：开考（题库卷在此刻出卷；已开过就接着答） |
| `GET` | `/api/student/exams/:aid/current` | 学生：当前卷子 / 我的答案 / 剩余时间 / 分数 |
| `POST` | `/api/student/exams/:aid/answers` | 学生：存答案（限时到点后拒绝） |
| `POST` | `/api/student/exams/:aid/submit` | 学生：交卷（客观题当场判） |

> 边界：**客观题的分数在交卷那一刻就定了**，主观题由老师给；总分只在老师点「判分并记账」时写进计分表，
> 所以学生交完卷会看到「等老师判主观题」。改判会先撤掉上一次那条账，不会重复计。

**容错与溯源**：

- 文件写坏了（JSON 语法错、项 key 重复、规则类型不认识、`avg` 没给等级表…）→ 服务端**打日志并继续用上一版方案**，不会把系统带下来；实在没有文件就用内置兜底（算法正确、文案降级）。
- 每条记分事件带 `schemeVersion`：知道这笔账是按哪一版方案算的。**方案不锁时间**——学期中按学情改分值，事实（等级、缺勤、卷面分）不动，只是重新折算；想留档用「结课归档」（P3）。

## 3. 数据：六张 CSV + 学生目录，进 git

数据全部存成 CSV，就是为了让 `git diff` 能直接读出「谁的分变了」。

| 文件 | 一行是什么 | 列 |
|---|---|---|
| `data/classes.csv` | 一个班 | `id,name,createdAt,rollcallRound` |
| `data/students.csv` | 一名学生 | `classId,sid,name` |
| `data/events.csv` | 一条记分记录（只追加） | `id,classId,sid,item,delta,kind,grade,late,raw,dims,reason,operator,createdAt,voided,voidedAt,voidedBy,evidence` |
| `data/rollcall.csv` | 本轮抽到的人 | `classId,sid,pickedAt` |
| `data/assignments.csv` | 一次作业 / 大作业 | `id,kind,title,dir,note,status,createdAt,openedAt,closedAt,updatedAt`（`kind` = work / project） |
| `data/exams/<作业id>.json` | 一场机试的试卷 / 题库（老师导入的原件；模板 `_template.json`） | 见「机试」一节 |
| `data/schemes/*.json` | 一份考核方案（课程级） | 见上一节「考核方案与计分规则」；`items[]` 决定评分表列、满分、规则与模块开关 |
| `data/submissions.csv` | 一次提交（只追加） | `id,assignmentId,classId,sid,name,dir,createdAt,files,changed,note,url,score,comment,gradedAt,gradedBy` |

> 课堂作业的**代码正文不进 CSV**：正文落在 `data/students/<班级id>/<学号>/作业/<作业id>/<提交id>/<原文件名>`，目录名即索引 id。
> `files` = 这次交上来的**整份**文件（老师那边要能跑起来看渲染），`changed` = 其中学生真改过的那些。
> 都是纯文本，跟 CSV 一样能 `git diff` 出「这节课谁改了什么」。
> `score` 空着 = 还没批（页面显示「待批」），跟「给了 0 分」是两回事。

复杂列的写法（保证单元格里没有逗号、能一眼看懂）：

| 列 | 写法 | 例子 |
|---|---|---|
| `dims`（大作业量规） | `键=分;键=分`，键排序 | `code=9;doc=3;func=12;ui=6` |
| `evidence`（证据文件） | `文件名\|URL`，多条用 `;` | `试卷 扫描.pdf\|/uploads/abc-试卷%20扫描.pdf` |
| `files`（提交的文件） | `相对路径`，多条用 `;` | `index.html;app.js` |
| `late` / `voided` | `1` / `0` | `0` |
| 空单元格 | 该字段没有值 | 机试记录没有 `delta` |

### 学生目录：每人一套档案

学生**一进名单**就在磁盘上有个自己的目录（不是等交作业才建），一学期的东西都往这里放：

```
data/students/<班级 id>/<学号>/
    作业/<作业 id>/<提交 id>/…      课堂作业：每次提交一整份代码，目录结构和「代码示例」一样
    大作业/<作业 id>/<提交 id>/…    大作业：学生交的附件（源码包 / 截图 / PDF）
    机试/                          期末机试交上来的答卷 + 成绩.xlsx
    记分/                          总评.xlsx（各项分数 + 总评）、明细.xlsx（记分流水）
    大作业/证据清单.xlsx            老师侧的评分证据索引（文件本体在 data/uploads/）
```

- **建目录的时机**：导入名单（`POST …/roster`）时整批建；服务启动时给老名单里还没目录的学生补一遍；
  交作业落盘前再兜一次。空目录不占空间，`git` 也不会记录空目录，文件进来才出现。
- **作业 / 大作业 / 机试 里的文件只有磁盘这一份**，删了就没了，别手删。
- **记分/ 里的是派生表**：真源在数据库的记分记录里，页面上实时算；
  给分或撤分后 300ms 内自动重写（`lib/scoresheet.js`），删掉也会自动重建。
  整班的分数表还是走「班级管理 → 导出总评 / 导出流水」（同一种 xlsx 格式）。
  > 这几张表在重构删 `server/` 时一度断过（函数搬过来了、调用点没搬），
  > 文件停在 11-03 而文档还在承诺它。现在由数据层的事件钩子触发，覆盖给分/撤分/恢复全部路径。
  所以 `.gitignore` 只忽略那三样，作业正文照旧进 git。
- **为什么要统一在这里**：期末要把「这个人一学期的东西」整包交出去（评优、复查、给学生本人看），
  按学号归档，压缩一个目录就是一套完整材料；按作业归档时得满磁盘捞。
- **清理**：删作业只清各学生的 `作业/<作业 id>/`；**删班会把 `students/<班级 id>/` 整棵删掉**
  （包括作业正文和记分快照）。从名单里删一个人不删他的目录 —— 记录留着，人不在了而已。

### 格式约定（别随手改）

- **UTF-8 无 BOM、LF 换行**（`data/.gitattributes` 里已锁死 `*.csv eol=lf`）。BOM 或 CRLF 会让同一份数据在不同机器上互相「整文件改行」。
- 含逗号 / 引号 / 换行的字段按 RFC 4180 用双引号包起来（记分原因里打回车也没问题）。
- **写入前统一排序**：班级按创建时间、名单按学号、流水按时间。同样的数据永远序列化成同样的文本，没改动就不产生 diff。
- 写盘是 `.tmp` 写完再 rename（原子写），200ms 内的连续改动合并成一次。

### git 工作流

```bash
git add data
git commit -m "第05课：考勤 + 作业A/B/C"
```

建议每节课下课提交一次——那时候 diff 就是「这节课谁拿了分」，可读性最好。回滚某一笔错分，`git revert` 或直接改那一行都能用。

### 两个坑

- **不要用 Excel 直接打开并保存这些文件**。Excel 会重写整个文件（加 BOM、改列序、把学号变成 `2.02501E+09`），一次保存就是几千行 diff。要核对数据用「导出 CSV」（那份带 BOM，专供 Excel）。
- **`config.json` 与 `uploads/` 不入库**：前者含教师口令，后者是二进制证据文件（无 diff 价值）。已写进 `.gitignore`。

### 备份 / 迁移 / 老数据

- **备份**：拷 `data/` 整个目录，或者直接用 git（推荐）。
- **迁移**：`data/` 一起拷到新机器即可。
- **老版本升级**：如果机器上还有 JSON 版的 `data/db.json`，首次启动会自动导入成 CSV（课堂作业那两张是新表，空着即可），并把原文件改名 `db.json.migrated` 留档，不会静默丢数据。

## 4. 与「机房投屏」的关系

投屏协议**一个字节都没改**，所以老方案的实测结论继续有效。中继从 Python 换成了 Node（同一个进程，端口也走 18730），好处是不用再开第二个窗口。

**采集尺寸**默认「跟随设备屏幕」（最高保真），另有「跟随当前窗口」（拖窗口自动重采样）与 1600×900 / 1280×720 / 1024×768 三档固定值。
帧率默认 15fps、质量 q85 —— 都是最高档。判断是否该降：看侧栏或设置页的「单台上行」，持续超过 0.8 Mbps 就先降帧率。

**投屏是全站常驻的**：推流实例挂在教师端布局上，点进讲义、点名、计分都不会断；只有整页刷新（F5）会断，因为媒体流跟着 document 走。
多开教师端标签页也不会互相踢 —— 谁在推流谁就持有「投屏模式」，另一个没开播的页面不会把它刷回未投屏。

沿用的四条现场经验（都在代码注释里标了出处）：

1. **必须拼接 WebSocket 分片**：浏览器发大消息会拆帧，只读第一帧 → 学生端长度校验不过 → 整帧丢弃 → 全班黑屏、只有鼠标处有图。
2. **推送节奏放 Worker 定时器**：教师全屏放 PPT 时页面被判隐藏，主线程定时器会被降到 1 次/秒。
3. **连上中继先发 `hello`**：否则「学生先上线、控制台后开」时教师端 `peers=0`，一帧都不推。
4. **背压只保留最新一帧**：个别学生机卡住不能拖垮整间教室。

另外补了一个老方案没有的细节：`http.Server` 的 socket 是 `allowHalfOpen=true`，对端 FIN 只触发 `end` 不触发 `close`——不自己收尾，**学生关掉页面后在线人数永远不归零**（自检里专门盯着这条）。

旧的 Python 版中继（`课堂工具/机房投屏/`）已随离线工具一起删除，投屏只走本系统的 Node 中继。

## 5. 自检

```bash
# 先启动服务，另开一个窗口
node server/selftest.js
```

覆盖 137 项，重点是几类容易悄悄坏的东西：

- **接口与算分**：登录鉴权、建班、名单导入、六种记分（考勤 / 互动 / 作业 / 机试 / 大作业 / 加分）、撤销后总分回退、学生只能读自己、学生不能读讲义、点名不重复、CSV 导出。
- **课堂作业**：新建默认未开始、没开始就提交被拒、开始后才能交、整份提交（`files` 全量 + `changed` 只留真实路径）、
  老师能读回每一个文件、提交按时间排序、学生看不到别人的提交、打分 / 清分、结束之后交不上来。
- **考核方案**：`/api/scheme` 列出的模块与方案一致、关掉的模块不出现在模块列表里、方案校验挡得住坏规则。\n- **机试**：导入题库（校验挡得住坏卷子）、题库卷两个学生拿到的题不一样、答案不下发、客观题交卷即判、主观题老师给分、卷面分按系数进计分表、答卷文件（exam.json + 答卷.md）落在学生目录。
- **大作业**：建作业不需要选课、默认未开始、开始前 403、说明/链接/附件至少要一项、附件落在学生自己的目录、
  老师能下载、**别的学生下不到**（403）、大作业不会被混进课堂作业列表、删除作业会清掉每个学生的附件目录。
- **状态判定**：心跳置为在线、报离立即离线、WS 通道断开后按缓冲时间下线；投屏状态只在开播时计入、观看页断开即消失。
- **投屏中继协议**：hello / peers / mode 广播、二进制逐字节转发、**100KB 分片消息拼接**、学生断开后 `peers=0`、非法 role 被关闭。
- **开播通知**：学生端 SPA 通道能收到「开始 / 停止投屏」（刚连上补发 + 变化时实时推），心跳接口 `/api/presence/ping` 也带回 `cast` 字段兜底 —— 学生端自动开投屏页全靠这三条路。

输出全 ASCII（避免 Windows 控制台编码干扰判断）。

## 5.5 教学公开与缓存策略

「教学公开」这条原则直接写进了接口与响应头：

| 内容 | 谁能看 | 响应头 | 代理/浏览器能不能缓存 |
|---|---|---|---|
| **课程材料**（学生讲义 `materials`） | **任何人**（不需要登录） | `public, max-age=60` | ✅ 能（公开内容，与身份无关） |
| **讲义**（教师讲稿 `lecture`） | 只有教师 | `private, no-store` | ❌ 不能 |
| 前端产物 `/assets/*`（文件名带内容哈希） | 任何人 | `public, max-age=31536000, immutable` | ✅ 能（一年） |
| 示例运行时库 `/examples/*`、`/vendor/*` | 任何人 | `public, max-age=86400` | ✅ 能（一天） |
| 课程图片 `/api/content/asset` | 任何人 | `public, max-age=86400` | ✅ 能（一天） |
| 教师端 / 学生端接口 | 登录后 | `no-store` | ❌ 不能（个性化数据） |

> 学生端的「课程材料」页现在**不登录也能打开**（把链接发给别人即可看课）；
> 讲义是教师内部内容，未登录取会得到 403。

**身份是三态，不是两态**（重要：游客页和学生首页是同一个 URL）：

| 状态 | 怎么认出来的 | 表现 |
|---|---|---|
| 已登录 | 有有效令牌 | 完整学生端（作业、分数、跟点名、投屏跟随…） |
| **游客**（从来没登录过） | 本地既没令牌也没登录记录 | 只读课程材料，侧栏底部「游客浏览 / 登录」 |
| **登录已失效** | 本地有登录记录，但服务端说令牌不认了（401） | **立刻跳登录页**，并显示「登录已失效，请重新登录。登录后会自动回到刚才那一页」 |

所以「游客页 URL 与学生登录后的首页相同」不会造成漏提示：
令牌一失效，`state.tokenExpired` 置位 → 路由守卫与全局监听都会把人送回登录页，
不会静默变成游客。三种状态的判定逻辑有单测：

```bash
cd web && node tools/test-identity.mjs      # 12 项：游客 / 已登录 / 已失效 / 重新登录 / 主动退出
```

**游客怎么用**：直接打开 `/student/materials`（不用登录）→ 左侧只有「课程材料」一个入口，
底部显示「游客浏览 / 课程材料公开可看 / 登录」；要交作业、看分数、跟点名再登录。
游客用到的公开接口只有一个：

| 接口 | 给什么 | 不给什么 |
|---|---|---|
| `GET /api/public/course` | 课程名 + 课次清单（id / 序号 / 标题 / 有没有材料） | 班级、名单、成绩、讲义正文 |

  optional，npm 仍会 ERESOLVE 报错），要再往上就得连 Vite 5 → 8、`@vitejs/plugin-vue` 一起升。
  本项目只用 `createRouter` / `createWebHistory` / `beforeEach` / `<router-link>` / `<router-view>`
  这几样，5.0.7 已包含 v5 的全部运行时改动，升级 5.4 换不到任何实际收益，只多一层构建链风险。
- **`vue` 下限写 `^3.5.34`**，与 vue-router 5 的 peer 对齐；写低了会让新机器装出跑不起来的组合。
- **构建目标与基线对齐在 `chrome109`**（见 `web/vite.config.js`）。
  早先是 `chrome78`（想多兼容一档老机器），但全站 163 处 **flex 容器的 `gap` 要 Chrome 84**、
  2 处 `height:100dvh` 要 **108** —— target 定 78 只是「语法能跑」，布局照样垮，
  反而制造「支持 78」的错觉（拿 78 打开：JS 不报错、页面全乱，比白屏更难查）。
  完整分析见 `docs/前端浏览器基线分析.md`。
  **要改这个数，三处必须同步**：`build.target` / `index.html` 的 `MIN_CHROME` /
  `check-compat.mjs` 的基线，并在机房真实浏览器上验一遍 ——
  只改一处会出现「产物白屏但兜底页认为浏览器合格」，老师看到一片空白。

### 兼容体检（改前端前后各跑一次）

后端跑在服务器上（Node ≥ 20），机房只开浏览器（Chrome 109）。这两条基线由脚本盯着：

```bash
node tools/check-compat.mjs            # 全查
node tools/check-compat.mjs --frontend # 只查浏览器基线
```

它查的是：`server/*.js` 能不能在当前 Node 上加载、`build.target` 有没有被抬过、
`src/` 与 `dist/` 里有没有 Chrome 109 不认的语法/特性、CSS 有没有用嵌套 `&`。
在开发机（新 Chrome + 新 Node）上全都毫无症状，到机房才炸 —— 所以钉成脚本。

## 7. 已知限制

- **第 12 课起的示例是 npm 工程**（有 `package.json`），代码练习 里预览跑不起来，页面上会给出提示；按《学生环境准备说明》用 `npm run dev` 跑。
- **教师端不限位置**：从 localhost、局域网 IP、别台机器打开都一样，口令对了就能进；投屏控制台认教师令牌，不认来源 IP。代码里没有任何按地址设卡的地方。
- **抓屏是浏览器管的，不是我们管的**：`getDisplayMedia` 只在「安全上下文」里存在（https / localhost / 被命令行加白的源）。所以要理解成两件事——
  - 用 **`打开教师端.bat`** 打开：它用一个专用 profile 启动 Chrome，白名单固定为 `localhost` + `127.0.0.1` + **你在文件里填的那个 IP**，所以任何地址下都能投屏（已实测：从 `http://192.0.2.20:18730` 点开始投屏 → `投屏中 · 1 人在看 · 15fps`，观看页正常收帧）。
  - **地址要手填，就一处**：用记事本打开这个 bat，最上面标着 `FILL IN HERE` 的区块里改一行——
    ```bat
    rem 换成 ipconfig 里看到的那个 IPv4
    set "LANIP=192.0.2.20"
    rem 1 = 用上面这个 IP 打开页面，0 = 用 localhost
    set "OPEN_VIA_IP=1"
    ```
    留空 = 只用 localhost（单机上课不用改任何东西）。只填裸 IP：带端口或 `http://` 会直接被拦下来报错，不会拼出一个坏地址。
    白名单是加在**跑这个 bat 的那台浏览器**上：服务在别的机器上时，要在实际用来上课的那台机器上跑 bat，并在里面填服务机的 IP。
  - 用普通浏览器直接输地址打开：localhost 下照常能投；**http + IP 这种地址 Chrome 会把屏幕接口收走**，点开始投屏会当场把原因和两条出路写出来（不拦按钮、不禁用功能，讲义 / 计分 / 点名全不受影响）。
- **「自动打开投屏页」最终由浏览器说了算**：`window.open` 不是用户点出来的就会被拦（Chrome / Edge 都拦，这是防止广告弹窗的底线，网页绕不过去）。所以做成三级兜底——
  1. 学生之前点过一次投屏页（本节课内那扇窗还留着）→ 直接把它跳过去并 `focus`，一节课只开一个标签页；
  2. 能开 → 新标签页自动落到 `/watch`；
  3. 被拦 → 页面底部浮一条「**老师开始投屏了**」横幅，点一下即可，点过之后本节课不再打扰（`先不看` 可关闭）。
  学生端发现开播有三条路，任意一条通就行：在场通道实时推、刚连上时补发、20 秒一次 `/api/cast/status` 轮询兜底（WS 被机房代理掐掉时只剩最后这条）。
- **投屏页不跟着窗口缩放**：默认 1:1 显示 + 滚动条 + 缩放工具，故意不做「自动塞满窗口」——老师机 1080p 的字塞进小屏会缩到看不清，宁可让学生自己拖、自己放大（见上文「投屏页按原尺寸显示」）。
- **投屏不做学生机锁定**：局域网 http 页面拿不到安全上下文，挡不住 Win 键 / Alt+Tab，纪律靠课堂管理（与原方案取舍一致）。
- **代码练习 的代码存在学生本机，不上服务器**：刷新、关浏览器都还在（`localStorage`，按人来分桶），但换机器 / 换浏览器 / 清浏览器数据就没了。这是刻意的——随手玩的代码不用收；要交给老师看的，走**课堂作业**的「提交」（那是唯一把代码送上服务器的地方，而且只送改过的文件）。
- **课堂作业交的是整份，但「改了什么」单独记**：`files` 是全份（老师要能跑起来看渲染），`changed` 是改动清单。
  学生改完又改回原样 = 等于没改，会被前端拦下（一个脏文件都没有时提示「还没改动任何文件」）。
  提交里只有该课目录下的文件；`../vue.global.js`、`../playground/sfc-boot.js` 这类跨目录的共用件仍由服务器按 `<base>` 提供。
- **审阅弹层的预览是沙箱跑的**：`sandbox` 不给 `allow-same-origin`，所以学生代码碰不到教师端的令牌；
  代价是示例里如果用了 `localStorage` / `sessionStorage`，在预览里会抛错（讲义示例目前没有这种）。
  要真机验证存储相关的作业，仍按课程里的办法用 `npm run dev` 跑。
- **老师端的提交列表是轮询的（8 秒）**：学生交作业走学生端的通知通道，老师端不挂 WS，靠定时拉取；刚交完最多晚 8 秒出现，页面切到后台时不拉。要立刻看，点「刷新」。
- **课堂作业 / 大作业的分数只能从模块进**：三张表里 `score` 是这一次提交的批阅结果，同时会写一条对应的记分事件（作业项按等级均分、大作业项按四维量规）。班级管理里这两项没有记分入口，要改分请回模块重批（会自动撤掉旧账），或在「全班流水」里撤销那一条。\n- **机试暂时还留在班级管理里录**：机试模块（出卷 + 批卷面分）还没做，所以「期末机试」的记分按钮暂时保留，按钮上带说明；模块做好后把它也挪进模块即可。
- **不联网**：所有前端依赖都在 `web/public/vendor/` 与构建产物里；Mermaid 只在文档里真出现图时才懒加载（3.2MB）。
- 浏览器基准 **Chrome 109**（机房现有设备的底线 —— **不是 Win7 遗留要求，Win7 已不支持**）；
  构建 target 与基线对齐在 `chrome109`。
- 单次上传证据上限 6MB，单条记录最多 6 个附件。
