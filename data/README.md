# data/ —— 运行数据目录

这个目录**不入版本库**（整目录在 `.gitignore` 里）。第一次启动服务时会自动生成全部需要的 CSV 与目录结构。

## 里面有什么

| 路径 | 内容 | 说明 |
|---|---|---|
| `config.json` | 教师口令、令牌密钥、课程内容目录位置 | **绝不入库**（含口令与密钥）；首次启动自动生成，之后可直接改文件 |
| `courses.csv` | 课程（id / 名称 / 学期 / 方案 / 内容目录） | 课程级设置 |
| `schemes/<id>.json` | 考核方案（分值、规则、模块开关） | 每个课程一份 |
| `classes.csv` | 班级（id / 课程 / 班名 / 人数） | |
| `students.csv` | 学生名单（学号 / 姓名 / 班级） | **含个人信息，不入库** |
| `events.csv` | 计分流水（考勤 / 互动 / 作业 / 机试 / 大作业） | 计分真源 |
| `assignments.csv` / `submissions.csv` | 作业定义与提交记录 | |
| `rollcall.csv` | 点名台账 | |
| `state.csv` | 运行时状态（点名抽到哪了、投屏同步到哪页、学生端菜单收起哪些） | 每次上课都变，不入库 |
| `students/<班级>/<学号>/` | 每个学生的目录：作业正文、大作业附件、记分快照、证据清单 | 提交的正文要进（能 diff），派生快照不进 |
| `uploads/` | 上传的文件本体（附件、评分证据） | 二进制，不入库 |
| `.trash/` | 导入/删除时的回收站（可捞回） | 不入库 |

## 备份与迁移

```bash
# 备份：整个 data/ 拷走就行
tar czf classroom-backup-$(date +%F).tar.gz data/

# 换机器：把 data/ 放到新机器的同一位置（或用 TS_DATA_DIR 指过去）
```

**这个目录就是「课堂的全部数据」**：课程、名单、成绩、学生的每一次提交都在这里。系统本体（代码）可以随时从镜像拉新的，数据始终是你的。

## 想从零开始

把 `data/` 整个删掉再启动即可（会重新生成空表）。注意：这会丢掉所有课程、名单与成绩。
