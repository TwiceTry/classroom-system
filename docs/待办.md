## 一、前端

### 1. 长列表虚拟化

`Assignments.vue` / `Projects.vue` / `Classes.vue`（1311 / 1196 / 1290 行）都是
「一次渲染全部行」。60 人以内感觉不出来，班级到 150 人以上会开始卡。

方案：`vueuse` 的 `useVirtualList`，或自己写一个固定行高的窗口化容器。
**前提**：行高必须固定（现在是固定的，改样式时要注意）。

### 2. `Scheme.vue` 拆分

`18 处 v-for` / 1251 行，是前端剩的最大的单文件。
拆法参考 `PgWorkbench`：按「考核项列表 / 编辑抽屉 / 量规编辑器」拆组件 + composable。

## 二、接口

### 3. `/api/pgsync` 去重

代码练习页里 `StudentLayout` 和 `PgWorkbench` **各拉一次**。
同步进行中时两次都会带回完整代码内容（老师推的那份）。

做法：在 `usePgSync` 里做模块级单例（共用 in-flight Promise），两处调同一个 `resumeOnce()`。

### 4. 班级页分页 / 懒加载

现在一次返回「名单 + 每人 8 项分数」：60 人 52KB 尚可。
若某个班 150 人 + 每人 8 项，会回到 150KB 量级。

做法：先只返回「名单 + 总分」，展开某个学生时再取明细（点开才拉）。

### 5. `/api/content/doc` 是否预取相邻课次

单篇正文 14KB，一次只取一篇是**对的**。
材料页首屏如果预取相邻课次会白拉（学生不一定往下翻）—— **目前没预取，保持现状**。

> 这条只是记一下"评估过、决定不做"，以后别再纠结。
