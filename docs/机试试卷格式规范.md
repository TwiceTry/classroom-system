# 机试试卷 / 题库 · 格式规范

> 给老师看的：把这份 JSON 交给系统，它就能校验、出卷、收答案、判客观题、算总分、出答卷文件。
> 模板文件：`data/exams/_template.json`（复制一份改内容最快）。
> 代码实现：`server/lib/exam.js`（校验 / 抽题 / 判分 / 出报告都在这里）。

---

## 0. 一句话版本

```jsonc
{
  "kind": "bank",                 // bank=题库随机卷，paper=统一卷
  "title": "期末机试",
  "duration": 90,                 // 分钟
  "sections": [
    { "id": "c", "title": "一、选择题", "type": "choice", "score": 5, "pick": 4,
      "questions": [ { "id": "c1", "stem": "题干", "options": ["A. …","B. …"], "answer": "A" } ] }
  ]
}
```

导入方式：教师端「期末机试」→ 新建 →「导入试卷 / 题库」→ 选这个 `.json`。

---

## 1. 顶层字段

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `kind` | 否 | `"paper"` / `"bank"` | 缺省 `paper`。`bank` = 题库随机卷；`paper` = 统一卷 |
| `title` | 否 | 字符串 | 卷面标题，学生端显示，也进答卷文件 |
| `duration` | 否 | 整数（分钟） | 0 或不填 = 不限时。题库卷建议填，否则学生没有交卷时限 |
| `fullScore` | 否 | 数字 | 卷面满分。不填 = 各段 `pick × score` 之和；填了但跟合计不一致，导入时给**提示**（以各段为准） |
| `sections` | **是** | 数组 | 分段（选择 / 判断 / 填空 / 简答各自一段最省事） |

未知字段会被忽略，可以加自己的备注（比如 `"_说明"`）。

## 2. 分段（sections[]）

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 否 | 段标识，缺省 `s1` `s2`… |
| `title` | 否 | 显示名，如「一、选择题（每题 5 分）」 |
| `type` | **是** | `choice` / `judge` / `fill` / `short`（见第 4 节） |
| `score` | **是** | **这一段的每题分值**（> 0） |
| `pick` | 题库卷必填 | 从本段抽几道。`paper` 卷可不填（= 全用）；填了就是取前 `pick` 道 |
| `questions` | **是** | 题目数组，不能为空 |

## 3. 题目（questions[]）

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 否 | 题号，全卷唯一（缺省自动生成）。**答题、判分、答卷文件都按它对齐** |
| `stem` | **是** | 题干（纯文本；要换行就用 `\n`） |
| `options` | 选择题必填 | 选项数组，形如 `["A. …", "B. …"]`；字母**按顺序**自动对应 A/B/C/D… |
| `answer` | 客观题必填 | 选择题写字母（`"A"`、多选 `"AC"`）；判断题写 `"对"`/`"错"`；填空题写答案文本；简答题写参考答案 |
| `accepts` | 否 | 仅填空题：其他可接受的写法，如 `["<script setup>", "script setup"]` |
| `explain` | 否 | 解析，判卷时老师能看到，也写进答卷文件 |

## 4. 四种题型与判分

| `type` | 学生怎么答 | 怎么判 | 判分要点 |
|---|---|---|---|
| `choice` | 单选（也可多选） | **自动** | 答案字母排序后比对，多选必须完全一致；`"ac"` 与 `"CA"` 等价 |
| `judge` | 点「对 / 错」 | **自动** | `对/是/true/T/1` 都算对；`错/否/false/F/0` 算错 |
| `fill` | 一个输入框 | **自动** | 去空格、不分大小写、全半角标点归一后比对；`accepts` 里的写法也算对 |
| `short` | 多行文本 | **老师判** | 系统只把参考答案给你看，分数由老师在判卷页填（0 ~ 该题分值） |

> 客观题在**学生交卷那一刻**就判完了（学生能看到「客观 50 分」这类数字）；
> 总分（卷面分）只有老师点「判分并记账」才写进计分表。

## 5. 两种出卷模式

| | `paper` 统一卷 | `bank` 题库随机卷 |
|---|---|---|
| 谁拿到什么 | 全班同一份 | 每人在**开考那一刻**抽题，各一份 |
| 题量 | 每段全部（或前 `pick` 道） | 每段随机 `pick` 道 |
| 稳定性 | — | 用 `作业id + 学号` 定随机种子：**同一个学生重进还是同一份**，换人才换卷 |
| 适合 | 期末统一卷、补考 | 防抄袭、多场次轮考 |

注意：`bank` 模式下 `pick` 必须 ≤ 该段题池数量，否则导入报错。

## 6. 校验规则（导入时会逐条报给你）

**报错（必须改，否则不导入）**

- `sections` 为空；某段没有题目；某段 `score ≤ 0`
- `bank` 卷某段没写 `pick`，或 `pick > 题池数量`
- 题目缺 `stem`；题 `id` 重复
- 选择题选项 < 2；没给 `answer`；答案字母超出选项范围（如 3 个选项却答 `D`）
- 判断题答案不是 对/错（含 true/false 之类）
- 填空题既没 `answer` 也没 `accepts`

**提示（能导入，但请确认）**

- 各段合计 ≠ `fullScore`
- `bank` 卷没设 `duration`（学生没有交卷时限）

## 7. 示例一：统一卷（最简）

```json
{
  "kind": "paper",
  "title": "期末机试 · 统一卷",
  "duration": 60,
  "fullScore": 100,
  "sections": [
    {
      "id": "c",
      "title": "一、选择题（每题 10 分）",
      "type": "choice",
      "score": 10,
      "questions": [
        { "id": "c1", "stem": "Vue 3 里创建响应式对象的 API 是？", "options": ["A. reactive()", "B. JSON.parse()", "C. setTimeout()"], "answer": "A" },
        { "id": "c2", "stem": "HTTP 方法里用于提交表单的是？", "options": ["A. GET", "B. POST", "C. FETCH"], "answer": "B" }
      ]
    },
    {
      "id": "s",
      "title": "二、简答题（每题 40 分，老师判分）",
      "type": "short",
      "score": 40,
      "questions": [
        { "id": "s1", "stem": "说说你怎么把一个页面拆成组件。", "answer": "参考点：按功能/复用/数据边界拆；props 向下、emit 向上。" }
      ]
    }
  ]
}
```

判分：选择题 2 × 10 = 20 自动；简答 40 老师给；合计 60 分（`fullScore` 写 100 会提示不一致）。

## 8. 示例二：题库随机卷（推荐期末用）

见 `data/exams/_template.json`，四段齐全：

```jsonc
{ "kind": "bank", "duration": 90, "fullScore": 100,
  "sections": [
    { "type": "choice", "score": 5,  "pick": 4, "questions": [ /* 6 道题池 */ ] },   // 20 分
    { "type": "judge",  "score": 5,  "pick": 2, "questions": [ /* 3 道题池 */ ] },   // 10 分
    { "type": "fill",   "score": 10, "pick": 2, "questions": [ /* 3 道题池 */ ] },   // 20 分
    { "type": "short",  "score": 25, "pick": 2, "questions": [ /* 2 道题池 */ ] }    // 50 分
  ] }
```

合计 100 分；每个学生从 6+3+3+2 道题池里抽出 10 道，各人卷子不同。

## 9. 计分与折算

- 卷面总分 = 客观题自动分 + 主观题老师给分（不超过卷面满分）
- 写进计分表的是**「期末机试」这一项**，按方案的规则折算：默认 `raw`，`卷面分 × 0.3`（满分 30）
  - 例：卷面 90 → 机试项 27 / 30
- 改判会先撤掉上一次那条账（计分表只追加 + 撤销，不会重复计）

## 10. 系统生成的「纸」

导入试卷的那一刻，系统就把卷子排成了一张**能打印的真试卷**；判分之后，再给每个学生出一张**他自己的答卷**。

### 10.1 试卷 / 答案卷（导入时生成）

`data/exams/<作业id>/` 下：

| 文件 | 是什么 |
|---|---|
| `试卷.md` / `试卷.html` | 空白卷：卷头（课程 / 考试 / 班级·学号·姓名·日期）、说明、各大题（每题分值、共多少分、本大题得分栏）、每题题干与选项，选项按两列排 |
| `答案卷.md` / `答案卷.html` | 同一张卷子的**答案版**：每题后面跟「参考答案 + 解析」。只给老师，不要下发 |

`*.html` 是 A4 打印版（宋体、页边距、题目不跨页断行），浏览器打开直接 `Ctrl+P` 就是一张卷子。

### 10.2 每个学生的答卷（判分后生成）

`data/students/<班级>/<学号>/机试/<作业id>/<提交id>/` 下：

| 文件 | 是什么 |
|---|---|
| `exam.json` | 机器读：卷子（含答案）+ 学生答案 + 逐题得分 + 总分 + 开始/交卷/判分时间 |
| `答卷.md` | 人看：卷头 + 卷面得分与构成 + 逐题「学生作答（选择题把选中的选项加粗标出）/ 对错 ✓✗ / 得分 / 参考答案 / 解析」+ 老师评语 |
| `答卷.html` | 打印版：跟真卷子一样，直接打印或存 PDF，学生拿到的就是一张答过的卷子 |

> 一句话：**交什么卷子、判多少分，最后都会变成那个学生名下一份「真卷子」**；期末整包交给学生、评优复查、存档，都是现成的。

### 10.3 不下载也能看

| 方法 | 路径 | 谁 |
|---|---|---|
| `GET` | `/api/teacher/exams/:id/paper-file/html`（`?answers=1` 是答案卷，`:fmt` 可换 `md`） | 老师：预览 / 打印空白卷 |
| `GET` | `/api/teacher/exams/:id/submissions/:subId/paper-file/:fmt` | 老师：看某个学生的答卷 |
| `GET` | `/api/student/exams/:id/paper-file/:fmt` | 学生：看自己那份（判完才有，没判会说「等老师判完」） |

## 11. 常见报错对照

| 报错 | 怎么改 |
|---|---|
| `第 1 段「xx」是题库卷，要写 pick（抽几道）` | 给该段加 `"pick": 4` |
| `要抽 6 道，但题池只有 4 道` | `pick` 调小，或往 `questions` 里加题 |
| `题「c3」的 id 重复` | 题 id 全卷唯一，改成 c3b 之类 |
| `题「c1」的答案「D」超出选项范围` | 选项只有 A–C，答案改成 A/B/C |
| `判断题答案只能是 对/错` | `"answer": "对"` 或 `"错"` |
| `填空题没给答案` | 补 `answer`（或 `accepts`） |
| `各段合计 90 ≠ fullScore 100`（提示） | 改分值/题量使合计为 100，或把 `fullScore` 改成 90 |

## 12. 兼容性

- 字段名区分大小写；字符串用英文引号
- 多出来的字段会被忽略（可以写 `"_备注": "..."`）
- 一个文件可以只有一段、一道题；空题目数组不行
- 想换卷：直接再导入一次（覆盖该作业原来的卷子）；已经开考的答卷不受影响
