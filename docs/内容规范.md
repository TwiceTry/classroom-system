# 课程内容规范（materials / lecture / 代码示例）

> 这份文档同时回答两件事：**内容该怎么写**、**系统怎么读**。
> 两者必须一致 —— 改解析规则时同步改这里，改这里时确认系统还认。
>
> 排课 / 考核 / § 编号索引见课程仓库的 `教学映射表.md`；
> 目录边界与维护流程见课程仓库的 `三方职能约定.md`。

---

## 0. 三个目录的定位

| 目录 | 给谁看 | 回答什么问题 | 系统里的入口 |
|---|---|---|---|
| `materials/` | **学生** | 学什么（知识点 + 原理 + 练习 + 拓展） | 学生端「课程材料」 |
| `lecture/` | **教师** | 怎么教（含 materials 全部学生内容 + 讲法） | 教师端「讲义」 |
| `代码示例/` | **学生跑** | 课程里讲到的代码，能照着跑 / 改 / 学 | 教师/学生端「代码练习」 |

三者**同名同号一一对应**：`第NN课-XXX` 在这三个位置都存在，指向同一节课。

---

## 1. `materials/` —— 学生讲义（替代 PPT）

### 1.1 必须包含

- 本节知识目标与知识点讲解（学生能直接看懂）
- 关键代码与原理
- `✅ 自测与练习`：题号 作业 1 ~ 作业 N，最实操的那题升级为可提交作业
- `📚 拓展阅读`：加分 / 拔高
- `🧪 配套代码`：**一行**指向 `代码示例/第NN课-XXX/`，并用一句话说明"打开后能看到什么"

### 1.2 禁止出现（这些属于 lecture）

- 教师向 / 教务向内容：90 分钟、代替 PPT、板书标记、评分量规、授课计划、课时分配
- 讲法提示：`💬 提问`、`⚠️ 易错预警`、演示动作、时间分配

### 1.3 小节层级

一级知识块用 `##`，一屏一个的细节点用 `###`。
（讲义里对应位置是 `####`，因为 `###` 被 `📺/🎤` 占了 —— 见 §4.2）

---

## 2. `lecture/` —— 教师讲稿（备课本）

### 2.1 开头固定元信息块

`📅 教学信息`（周次 / 班级 / 地点 / 学时）、`🎓 素质目标`、`📖 知识目标`、
`🛠 能力目标`、`🔑 教学重点`、`🧗 教学难点`、`🇨🇳 思政融入点`、
`📝 作业`（= materials 自测第 1 题）

### 2.2 主体：屏幕与讲稿交替

按小节交替：

```md
### 📺 屏幕     ← 学生屏幕上应出现的内容（materials 对应知识的镜像）
### 🎤 讲稿     ← 教师口播
```

**两条硬规则**：

- `📺 屏幕` 必须与对应 `materials` 内容**逐字对齐**（它就是 materials 的投影）
- 每个小节 `屏幕` 与 `讲稿` **必须配对**（数量相等）

`🎤 讲稿` 可自由加任何教学法：提问 / 易错预警 / 演示动作 / 时间分配。

### 2.3 小节层级

一级知识块 `##`，细节点 `####`（写在 `### 📺 屏幕` 之内）。

### 2.4 尾部

`⏱️ 时间分配总览`、`📝 课后记`（教学反思模板）。
这两个**不写 `### 📺`**，不参与和 materials 的同步。

---

## 3. `代码示例/` —— 可运行实例（同时是学生分发包）

### 3.1 对应规则

- 与 materials / lecture **同名同号**（`第NN课-XXX`）
- **非课时补充**：不占 `第NN课` 编号，命名 `补充-XXX`（如 `补充-JS基础复习`），三处同名；
  示例直接在「代码练习」里预览 `index.html` 即跑（纯静态、无依赖）
  - **练习型补充课的结构**：`index.html` = 渲染页 + 判分框架（学生**不改**）、
    `q1.js`~`qN.js` = 学生逐题作答（题号与 materials 的 `✅ 自测` **一一对应，不许换号**）、
    需要演示对照再给 `demo.html`
  - 判分框架必须保证两条路径行为一致：Playground 里改 `qN.js` 立刻重跑
    （源码来自内存字典 `__SFC_FILES__`）与在「代码练习」里预览 `index.html` 读磁盘 `.js`
- materials 里每个 `✅ 自测`、`💡` 案例、反例，都能在示例里找到对照实现

### 3.2 `index.html` 是纯壳

```html
<script src="/api/assets/lib/vue.global.js"></script>
<script src="/api/assets/lib/vue3-sfc-loader.js"></script>
<script src="/api/assets/lib/sfc-boot.js"></script>
```

- 业务与布局全在 `App.vue` 及子组件
- 入口是同目录 `main.mjs`：`import App from './App.vue'` + `createApp(App).mount('#app')`
- **不需要任何构建**

> **路径必须写绝对路径 `/api/assets/lib/...`。**
> 运行时库现在放在课程 assets 下（`data/courses/<课>/content/assets/lib/`），
> 由 `/api/assets/*` 提供（免登录、代理缓存 365 天）。
> 从前写 `../vue.global.js` 或 `/lib/vue.global.js` 的页面已经全部迁移，新写页面不要再用旧路径。

### 3.3 一课多页

同一课要加第二个页面（课堂实验台 / 进阶 demo）时，再写一个 `xxx.html`
（同样三行依赖，启动脚本上加 `data-entry="xxx.mjs"`）+ `xxx.mjs` + `Xxx.vue`。

「代码练习」的「预览页面 ▾」会自动列出该课所有 `.html`，学生也能在文件树里改对应源码。
第 04/05 课 `lab.html`、第 05 课 `watch.html` 就是范例。

### 3.4 环境分期

- 第 1 课：纯 HTML 直接看
- 第 2~18 课：课堂系统「代码练习」（免安装、离线，学生不用自己装环境）
- 第 19 课起：`npm install && npm run dev`（Vite 工程）

### 3.5 禁止

- 不塞与课程无关的代码
- **不放教师专用工具**（那些归课堂系统）

## 4. 讲义 ↔ 材料 · 小节对应

> 给「继续整理 `lecture/` 与 `materials/`」的人或 AI 看。
> 读完应能独立把一节课拆到位，并按 §4.8 自证改对了。
> **不新增任何标记**：节点靠标题本身对应；层级只影响排版，不参与匹配。

### 4.1 三条规则

```md
## 🧱 单文件组件 SFC        ← 讲义
## 🧱 单文件组件 SFC        ← 材料，标题一样 = 同一节点
```

1. **同一节点的两侧标题，写成同一个。**（判定细则见 §4.3）
2. **讲义里带 `### 📺 屏幕` 的节，材料里必须有同名标题。**（`📺` 是「这节要给学生看」的开关）
3. **软约束：最小叶子节点最好一屏讲完。** 超了就在**两侧同时**下沉一级，拆出同名子标题。

规则 3 是重点 —— 没有它就是：**一节跨三屏时，学生端只能等你滚到下一节才跳，中间内容被快速略过。**

### 4.2 层级怎么用

讲义里 `###` 被 `📺 / 🎤` 占用了，所以两侧的层级**不一样**，但**匹配只看标题，不看层级**。

| 角色 | 讲义怎么写 | 材料怎么写 |
|---|---|---|
| 一级节点（一个知识块） | `## 标题` | `## 标题` |
| 细节点（一屏一个） | `#### 标题`（写在 `### 📺 屏幕` 之内） | `### 标题` |
| 结构标记（不参与同步） | `### 📺 屏幕` / `### 🎤 讲稿` | —— |

> `###` 在讲义里也能当细节点，系统同样认（现有内容里就有 `### 💻 同一件小事…` 这种，两侧同名）。
> 但它和 `### 📺 / 🎤` 同层，**人看着容易分不清「这行是结构还是内容」**，所以新拆的节点推荐一律用 `####`。

### 4.3 「同一个标题」的判定

忽略这些差异，其余**逐字一致**：

| 忽略 | 例子 |
|---|---|
| 行内 Markdown 标记 | `**Props**` = `Props` |
| 全角/半角冒号 | `Props：父传子` = `Props: 父传子` |
| 括号形状 | `Props（父 → 子）` = `Props(父 → 子)` |
| 所有空白 | `Props（父 → 子）` = `Props（父→子）` |
| 英文大小写 | `SFC` = `sfc` |

**不忽略**：emoji、括号里的字、标点、用词。
所以 `⚠️ 易错点` ≠ `⚠️ 易错点 / 收尾`，必须统一。

### 4.4 什么算「一屏」

按材料正文（学生看到的那份）算，满足全部三条：

| 指标 | 上限 |
|---|---|
| 正文字数（不含空白） | **≤ 900 字** |
| 代码块个数 | **≤ 3 个** |
| 表格行数 | ≤ 12 行 |

超了就拆。经验值：**一个代码块 + 两三段话** ≈ 一屏。

### 4.5 拆的例子

真实案例：第 08 课「📥 Props（父 → 子）」，922 字 / 2 个代码块。

**改造前**（子组件代码、父组件代码、校验写法全挤在一屏里）：

```md
## 📥 Props（父 → 子）

### 📺 屏幕
（子组件 Child.vue 一整块代码 + 父组件 App.vue 一整块代码 + 对象写法校验 + 三行结论）

### 🎤 讲稿
（怎么讲）
```

**改造后**（讲义下沉为 `####`，材料下沉为 `###`，标题同名）：

```md
## 📥 Props（父 → 子）          ← 讲义

> 15 分钟 · 先让学生判断「哪块是父、哪块是子」，再讲语法

### 📺 屏幕
#### 最小写法：父 `:属性名` 传，子 `defineProps` 接
（子组件代码 + 父组件代码 + 「props 只读」一句）

#### 对象写法（推荐）：类型 + 默认值 + 校验
（defineProps 对象 + 引用类型默认值必须用工厂函数）

### 🎤 讲稿
（怎么讲；这里可以随便用 ### 之外的层级，不参与同步）
```

```md
## 📥 Props（父 → 子）          ← 材料

### 最小写法：父 `:属性名` 传，子 `defineProps` 接
（子组件代码 + 父组件代码 + 「props 只读」一句）

### 对象写法（推荐）：类型 + 默认值 + 校验
（defineProps 对象 + 引用类型默认值必须用工厂函数）
```

注意：`##` 一级标题**保留**，只是把它的正文拆成几个 `###`。
这样学生端还能按「大块」看目录，老师也能按块跳。

切分的边界不是「字数」，是**内容**：一眼能看出「这两块是两件事」（父传子 vs 校验规则）
才值得拆；拆完每块应是「一个代码块 + 两三段话」。
反过来，同一个道理正反两段话就别拆 —— 拆碎了学生端会频繁跳动（见 §4.10 最后两条）。

### 4.6 讲义整体结构

```md
# 第08课 · 组件通信（上）：组件结构 / Props / Emit（教师讲稿）

> 周次 / 目标 / 重点难点 / 作业 —— 教师向，不参与同步

## 🎯 本节课你会学到

> 2 分钟

### 📺 屏幕
（可与材料同节一致，也可以只放要点）

### 🎤 讲稿
（怎么讲）

## 🧱 单文件组件 SFC

> 8 分钟 · 强调「一个文件一个组件」

### 📺 屏幕
#### 一个 .vue 文件长什么样
#### template / script / style 各管什么

### 🎤 讲稿
…

## ⏱️ 时间分配总览（90 分钟）

（教师专属，**不写 `### 📺`**，不参与同步）

## 📝 课后记（教学反思 · 课后填写）

（同上）
```

附加信息（时长、提示）一律写在标题**下面一行**的引用块里，不进标题。

### 4.7 怎么改（执行顺序）

1. 挑一个超标节点，先看材料里它的内容能自然分成几块（通常按「一个概念 / 一个示例」切）
2. **先改材料**：插 `###` 子标题
3. **再改讲义**：在同一个 `### 📺 屏幕` 里插同名 `####` 子标题，把对应内容挪进去
4. 按 §4.8 逐条自查
5. 一节课改完再提交：

   ```bash
   git add web前端框架开发/lecture web前端框架开发/materials
   git commit -m "docs(内容): 第08课 拆分长节点，细到一屏"
   ```

> 旧的 `课堂系统/server/check-sections.js` 已随 `server/` 目录移除，现在靠 §4.8 的硬指标人工自查。

### 4.8 验收标准

- 两侧 `##` 同名、每叶 ≤900 字 / ≤3 代码块、`📺` 与 `🎤` 成对，逐条对完没有遗漏
- 打开讲义页（教师端 → 讲义），滚到任意 `####` 子标题，右上角提示是
  `学生材料已跳到「H4 …」`（H4 表示当前是四级标题节点）
- 学生端能停在子标题上，而不是整节跳到底
- 页面上看不到任何 `{#...}` 之类标记

### 4.9 学生端会怎么表现

| 你在讲义里滚到 | 学生端 |
|---|---|
| `##` 一级节点 | 跳到同名一级节点 |
| `####` 细节点 | 跳到材料里同名 `###` 子标题 |
| 没拆的长节 | **只能整节跳**，节内跨屏内容仍会被略过 —— 不是 bug，是还没拆 |

所以「拆到位」直接决定跟随的细腻程度。

### 4.10 常见错法

| 写法 | 问题 |
|---|---|
| 只在材料里拆 `###`、讲义没跟着拆 | 该子节点「材料独有」，老师在讲义里滚到那里时只能跳到上一级 |
| 讲义里用 `###` 当细节点 | 会与 `### 📺 / 🎤` 冲突，不生效（细节点必须用 `####`） |
| 两侧子标题措辞不同（`各管什么` vs `分别负责什么`） | 视为不同节点，不同步 |
| 子标题重名（同一节里两个 `### 小结`） | 定位到第一个，后面的失效 |
| 拆得太碎（每段一个标题） | 学生端会频繁跳动，反而干扰；一屏一个刚好 |
| 给教师专属节写 `### 📺` | 会要求材料也有同名节 |

## 5. 系统怎么读这些内容

### 5.1 文件名解析

`api/src/lib/content.js` 里两个正则决定"哪些文件算一节课"：

```
RE_LESSON  第NN课-XXX.md
RE_SUPP    补充-XXX.md
```

**改课号 / 标题命名规则时，这里必须同步改**，否则教师端讲义、学生端材料会少课。

### 5.2 讲义 → 材料的跟随

教师端讲义页滚到某个节点时，学生端材料跳到同名标题（判定规则见 §4.3）。
实现上只匹配标题文本，不看层级 —— 所以讲义 `####` 能对上材料 `###`。

### 5.3 运行时库

示例页面的三行 `<script>` 指向 `/api/assets/lib/*`：

```
data/courses/<课>/content/assets/lib/
  vue.global.js        前端代码练习页（pgPreview）用
  vue3-sfc-loader.js   同上，1.8 MB
  sfc-boot.js          同上
  vue.global.prod.js   课程示例用
  jquery.min.js        课程示例用
```

由 `api/src/routes/compat.js` 的 `/api/assets/*` 提供：
免登录、路径越界检查、静态资源 `max-age=604800`（代理侧 365 天）。

### 5.4 内容目录

`data/config.json` 的 `courseDir` 指向课程内容根目录（或环境变量 `TS_COURSE_DIR`）。
系统**只读**这三个目录，没有任何内容副本 —— 改完文件刷新页面即生效。

## 6. 改完自检

- ☐ 三处（materials / lecture / 代码示例）文件名一致（同名同号）
- ☐ 全库所有 `代码示例/` 引用路径都存在
- ☐ `materials/` 无教师 / 教务向残留
- ☐ `materials/` 都有 `🧪 配套代码` 行
- ☐ `lecture/` 元信息块齐全
- ☐ 每课 `屏幕` 与 `讲稿` 数量配对
- ☐ 两侧 `##` 同名、每叶 ≤900 字 / ≤3 代码块
- ☐ 示例 `index.html` 用的是 `/api/assets/lib/...`（不是 `../vue.global.js` 或 `/lib/...`）
- ☐ 课号统一为「第 NN 课」，无「章」字残留
